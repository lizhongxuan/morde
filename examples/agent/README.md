# Codex 平台 MCP 接入

首版只使用平台 `/mcp`，由 Portal API Key 鉴权。

1. 在门户创建 API Key，将值保存在本机进程环境变量 `CH_CLOUDHOST_API_KEY`。
2. 把 `codex/config.toml` 中的 URL 改为实际门户地址，配置只记录环境变量名。
3. Codex 调用 `host_create`，轮询 `host_get` 到 running，再用 Shell、文件、AI 自有浏览器和可用的原生桌面工具操作同一主机。桌面/窗口工具仅在运行端探测到可用 X display 后提供。
4. 开发服务在工作目录内后台运行并监听 `0.0.0.0` 的非 8080 端口；`preview_url` 返回私有地址，用户先从门户进入主机再打开预览。
5. 删除主机默认保留工作目录；已有目录可在下次创建主机时重挂。

共 31 个工具。平台调用不需要主机令牌、CDP 或客户端 SDK。真实凭据只留本地环境，不写进配置、日志或仓库。禁止上传或发送本地用户文件；验证使用本地合成数据。
