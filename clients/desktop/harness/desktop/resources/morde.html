接续本机 Codex 会话

Codex 在本机运行。选择 CODEX_HOME profile 后，按线程逐项授权；Morde 仅同步已授权范围。Codex Desktop 自身的即时变化无法从 App Server 通知中订阅，页面会用有界快照核对已授权线程的稳定历史。

上传项目到云端电脑

选择云端电脑和本机项目文件夹，再点击上传。每次只从本机上传到 ~/workspace/project/<项目名>/；云端修改不会下载到本机。电脑关机时，云端确认与电脑应用是两个状态。
