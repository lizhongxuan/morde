# Morde 用户使用说明

> 更新：2026-10-24。面向用户的完整说明统一维护在 [HTML 使用指南](morde-user-guide.html)，可直接在本地浏览器打开。

## 从哪里开始

首版必需范围见 [三项同步说明](morde-user-guide.html#migration) 与 [设计方案第 4.1 节](Morde多端托管与共享工作区设计方案.md)：上传独立 workspace 后创建 / 绑定电脑、云端下载只补本地缺失文件、PC App 双向实时同步。需显示大小与进度、支持续传，已有差异保留并提示。然后按 [接力说明](morde-user-guide.html#review-path) 补原生 AI、网站鉴权与独立托管；手机后置。以上仍待实现与验收。


- **日常在电脑前：**查看 [本机 AI 与本地代码](morde-user-guide.html#start)，继续使用原有项目和客户端，为需要随身继续的项目启用 Morde 连接。
- **离开后继续用同款 AI：**查看 [同款 AI 云端接力开发](morde-user-guide.html#phone)。准备云端工具并完成登录，同步项目后在手机直接写代码、部署网站，回来再同步本地。
- **通过手机 IM 交办：**查看 [Morde IM 与云端画面](morde-user-guide.html#phone-im)，由服务端 Agent 操作指定电脑；这个入口继续保留，与云端电脑内的 AI 工具分别选择。
- **手机交办 PC 应用：**查看 [微信、QQ、飞书等云端应用](morde-user-guide.html#pc-apps)。用户安装兼容客户端并登录，手机让具备桌面能力的 AI 查找、整理和草拟；不要求先同步本机代码。
- **项目来回迁移：**查看 [本地与云端双向交接](morde-user-guide.html#migration)，了解提前准备、增量同步、核验和回来比较成果的流程。
- **继续原本机 AI：**查看 [Codex、Kiro、Claude Code 接入评估](morde-user-guide.html#local-ai)，区分已公开接口、原会话接续限制与 Morde 尚未实现的连接。
- **需要云端工具或自己部署：**查看 [云端电脑与 MCP](morde-user-guide.html#cloud-tools)、[部署准备](morde-user-guide.html#deploy)。具体配置以 [部署说明](../deploy/single/README.md) 为准。
- **了解当前完成范围：**查看 [G01–G14 实现缺口](morde-user-guide.html#availability) 与 [统一需求及验收要求](Morde多端托管与共享工作区需求文档.md)。

## 使用范围

PC 用户端已提供云端电脑、工作区、通知、客户端、模型连接、API Key 与账户设置页面。账户设置可查看当前账号、修改登录密码及管理已登录客户端；修改密码会撤销现有会话。自有云端电脑已有共享成员管理入口，可选择桌面查看/操作、终端或 MCP 权限，并在授权和撤权前确认；账号存在性与真实服务权限仍待联验。

当前为桌面开发预览，单机安装仍有手工步骤。现有云端工作台和 MCP 是基础能力；本机项目接入、workspace 同步、跨设备续聊和 AI 交接仍属规划，不能把原型或官方接口说明当作已接通。内置助理与计划通知仍需整栈验收；本地挂载、邀请共享、集群与迁移不作为当前已交付能力。

手机是第二个核心场景，继续基于本地 [project/nanoMuse](../project/nanoMuse/README.md) 源码二次开发。iOS 本地 MVP 已在既有四栏中接入 Morde 主会话、电脑、Workspace 和通知入口；“设置”中新增 Morde 账户页，展示名称、账号 ID 与服务地址，退出前需要确认。Minis 与独立 Morde 通用 iOS target 构建均通过，账户文案已纳入 9 种语言；模拟器、真机、签名和真实服务尚未验收。成员、安装、模型连接、API Key 管理和 Workspace 文件/同步仍待迁入。完整边界见需求第 1.2 节。新增 S09 直接使用云端电脑内的同款 AI：首次准备工具和官方登录，后续复用；文件同步不自动恢复原对话，停止写入后才接回代码。网站经 Morde 网关直接访问，服务与 AI 会话分别托管。原 S05 手机 IM 委派继续保留；本机 AI 消息连接是可选增强。具体见需求 R13、验收 A20–A24 与缺口 G09–G11；尚未登录或部署真实环境。

新增 S10 / R14：云端安装 PC 应用，手机委派 AI 实际操作。推荐复用 Morde IM、现有任务和桌面通道；程序、个人配置、登录与操作能力分别核验。官网存在 Linux 发行版不等于在 Morde 已支持，首次按测试账号完成安装、登录、指定内容读取、草稿与停止恢复。验收 A25–A28、缺口 G13/G14；手机界面仍后置，未执行安装或访问真实应用数据。
