### 需要核对的接口及兼容边界

| 边界 | 必须核对的内容 |
|---|---|
| 服务端 ↔ PC/iOS | 实际 base URL、capabilities、HTTP/SSE/Hub 版本、TS/Swift fixture、Client 权限、幂等与错误码；所有宣称支持的路径真实装配 |
| worker ↔ dsh ↔ Host 工具 | `(server_instance_id, user_id)` 账号归属、引擎/插件/检查点版本、各自实例代次和短期授权；停止、完成及未知结果语义一致，不因回退重放副作用 |
| Host/PC/iOS ↔ Workspace | Syncthing 设备授权、服务端持久目录、三端文件一致性、300 MiB 单文件与 5 GiB 每 Workspace 准入、冲突/撤权、稳定输入快照和产物读回；iOS 显式文件上传/下载与同一目录合同一致 |
| 个人同步与历史导入 | 对象唯一 ID/所有者、schema、mutation/cursor/tombstone、附件引用；导入历史不执行，恢复备份不复活已删除数据或已撤销权限 |
| 构建与升级 | PC appId/userData/安全存储、iOS Bundle ID/AppGroup/Keychain/extension、服务端迁移版本；列出实际支持组合，不承诺未测平台 |
