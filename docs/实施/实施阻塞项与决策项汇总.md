## 2. 已定方案

| 决策 | 原因与结果 |
|---|---|
| 保留runsc，宿主隔离 | 固定OSB 1.1.1的runsc+networkPolicy实测400：egress sidecar依赖gVisor不支持的NAT。现移除networkPolicy/sidecar，唯一cloudhost/chbr0网桥+nftables；真实创建已恢复。 |
| 受保护公共DNS | runsc专网下Docker内嵌127.0.0.11解析失败。只读挂载1.1.1.1/8.8.8.8配置，guard核对真实OSB、runtime参数、DNS与规则指纹；不开放宿主DNS/私网。 |
| 保留最小安全边界 | 公网允许，metadata/宿主/私网/同桥peer/root raw拒绝；实际CPU2/4GiB/pids4096。owner、session/API Key/ticket/Host Cookie/Origin、脱敏/审计/metrics、结果不明Create不重发和卷CAS均保留并验证。 |
| 单一基础逻辑 | Host使用creating/running/stopping/stopped/failed/deleting/deleted；模板 `onIdle=disabled`，由用户显式释放/恢复计算资源并保留Host、Workspace与runtime数据。跨实例活动租约完成前不启用自动空闲回收。17个MCP工具、一个Codex示例。移除项对应代码/SQL/API/UI/配置/测试fixture同步清理，不留兼容入口。 |
