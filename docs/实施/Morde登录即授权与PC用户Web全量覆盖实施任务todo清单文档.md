## 1. 修改边界与顺序

- **服务端**：复用现有账号密码校验，新增客户端登录、安装绑定用户 Web 会话和整组撤销；Workspace Sync 改为实时核对安装、账号及 Workspace 权限；当前用户功能以 Host、Workspace 与即时聊天服务为准，任务/计划停用按 D0、T07、T08 收口。
- **用户 Web**：复用当前 Portal 页面及 Workbench，删除设备码批准页；客户端列表只显示安装和撤销，不显示手选 Workspace 授权。Admin Web 保持独立。
- **PC**：nanoMuse Electron 壳只保留本机登录、安全存储、目录同步和托盘；隔离视图加载同一份 Portal 用户 Web，覆盖全部用户路由和操作，删除本地重复的 Task/Host/通知页面与 API broker。
- **手机原生端**：Android/iOS 改为应用内账号密码登录，不再展示配对码；手机 Web 继续使用普通 Portal Cookie。此次不扩展手机端功能范围。

执行顺序：**T22.15.1–.3 服务端合同 → T22.15.4 Portal → T22.14.1–.3 PC → T22.15.5 手机原生适配 → T22.15.6 删除旧配对 → T22.14.4 全量验收**。前后端可在开发中分步接线，最终构建不得保留两套运行路径。

## 2. 接口与数据变化

| 接口/边界 | 目标合同与调用方 | 必须核对 |
|---|---|---|
| **新增** `POST /api/auth/client-login` | PC/Android/iOS 提交账号、密码、平台、安装名和幂等键；可携原安装 ID 续期。成功原子登记安装并返回安装 ID、30 天 Client 凭证；PC 另返回独立 Sync 凭证及短期安装绑定用户 Web 会话秘密，不设置普通浏览器 Cookie | 复用 `CredentialService` 的密码验证、限流、审核和强制改密规则，但不能先创建普通 Portal Session 再补安装。失败无半创建安装；同一幂等键串行重试替换未确认秘密并作废旧秘密；密码/令牌不进日志 |
| **新增** `POST /api/auth/client-web-session` | PC 主进程用有效桌面 Client bearer 续取短期安装绑定用户 Web 会话；不会延长 30 天 Client 凭证 | 校验安装未撤销、账号仍获批准、客户端平台和凭证归属；手机 Client 无权调用。返回的秘密仅由主进程写入隔离分区的 HttpOnly、Secure、SameSite Cookie |
| **新增** `POST /api/auth/client-logout`；**修改** `POST /api/auth/logout` | 当前安装的 Client bearer 主动整组撤销；PC 内嵌用户 Web 点击现有“退出”时，其安装绑定 Session 也整组撤销；普通浏览器 Session 仍只退出自身 | Client、Sync、安装绑定 Web Session 和由其签发的 Host/Gateway 会话一起失效；断网本地退出须提示用户可从 Portal 远程撤销 |
| **保留并修改** `GET /api/clients`、`DELETE /api/clients/{id}` | Portal 和 PC 内嵌用户 Web 查看/撤销本账号安装；移除向用户展示的静态 Workspace grants | 跨账号不可见、不可撤销；列表不回传秘密；撤销后活动连接在既有复核周期内断开 |
| **修改** Portal Session、Host ticket 与 Workspace Sync 鉴权 | Session 记录安装 ID，以非空安装 ID 识别只供客户端用户 Web 使用的会话；PC Session 可访问全部用户 Web API，但拒绝 `/admin`、`/api/admin/*`；由该 Session 签发的 Host ticket 继承安装 ID。Sync 凭证不再以预选 `workspace_ids` 判断权限 | 每个用户 Web/API 请求、Sync 操作和 Gateway 长连接复核安装有效；Sync 仍只可访问账号当前拥有且 ready 的 Workspace，`KindDevice` 不可访问 Task/Host |
| **删除** `/api/client-authorizations` 创建/轮询/核对/批准/拒绝及 `/client-authorize` | PC、Portal、Android、iOS 改用上述登录合同，OpenAPI/生成类型/测试同步更新 | 旧码不能再领取凭证；保留历史审计，旧待批准记录和旧安装令牌在切换时安全失效；最终包无配对入口 |

服务端只新增后续版本迁移；已发布的 `server/migrations/00043_client_installations.sql` 等不回改。当前 `tokens.client_installation_id` 约束不允许 Session 关联安装，现有 `Principal.AllowsWorkspace` 又依赖静态 `workspace_ids`；两处都必须随新合同调整。安装 ID 是公开标识，不是凭证。平台字段不能代替账号密码或令牌验证；桌面 Client bearer 可续取完整用户 Web 会话，必须按完整用户权限保护。
