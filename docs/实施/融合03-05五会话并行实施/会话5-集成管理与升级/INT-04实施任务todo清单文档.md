## 实施合同与边界（本次）

- 邀请只记录 Morde 内的邀请码归因和账号状态；注册仍待管理员审核；不迁移旧 Cloud 历史、不写 IP 指纹、不发放邀请/贡献奖励，也不提供禁用/删除被邀请账号的批量操作。
- 管理站点统计只来自 Morde `sites` / `site_releases`；不请求 GitHub 或流量服务。外部 Demo、GitHub 统计明确标为未配置/未采集。运营提示默认关闭，由管理员显式配置后通过只读公共接口返回。
- （历史口径，已由 2026-11-03 规则覆盖）本期没有可安全复用的全局 token allowance 设置；预算继续按用户使用现有模型预算接口配置，缺少配置时模型调用保持明确拒绝。新用户没有默认模型预算。普通数据和个人数据额度仍分开。
- 个人数据额度 GET/PATCH 与页面已存在；补齐同事务审计并用本地浏览器验证查询、保存及错误状态。
