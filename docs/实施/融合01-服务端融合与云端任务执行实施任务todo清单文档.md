修改 `server/` 的身份、会话、Task、模型、worker、存储和运行端适配；复用 `project/morde-runtime`、Workspace 协议。已新增的 `project/nanoMuse/harness/morde-cloud-runtime/` 是无界面 dsh 入口，继续补齐账号级 Runtime 归属及隔离。业务 API/账号/权威状态仍只在 Morde；不运行另一套 Cloud、Go Agent 循环或用户云端会话主库。

当前继续使用 dsh，不把 Hermes-agent 作为 F01 必需依赖。将来若引入替代引擎，须先证明账号隔离、恢复、Host 工具、审批/撤权、用量和配额均接入 Morde，且不产生第二套业务权威。

客户端主界面归 03；Hub/个人同步/目标例程和管理页面归 04。本文包含持久审批、任务通知和文件产物，不依赖这些后续功能。模型、技能和工具存在云端依赖时必须显式检查，不能借用手机保持在线。
