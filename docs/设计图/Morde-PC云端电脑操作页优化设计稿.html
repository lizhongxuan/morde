设计取舍

红框中的主机状态、到期倒计时、工作台等待提示和桌面连接提示不再分块重复展示。远程桌面区域直接承载唯一的连接状态；进入操作后优先显示桌面画面。

  • 顶部工具栏桌面、终端、文件、VS Code 仍保留，压缩为工作台标签；续期移入“更多操作”。交还失败时显示“重试交还”按钮。
  • 桌面画面上沿适应窗口、键盘、找回窗口、全屏改为贴近画面的轻量图标按钮；未连接或无控制权时按权限禁用键盘操作。
  • 去掉重复项移除常驻的主机名、运行状态、剩余时长和重复连接提示；“Alt+Tab”和“找回窗口”目前触发相同操作，保留更易理解的“找回窗口”。
  • 状态与错误等待、断开或失败只在桌面区域显示一条状态；失败时在同一区域给出“重新连接”操作，交还失败则由工具栏的重试按钮承接。
