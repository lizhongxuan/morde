# Morde PC 端设计稿逐页逐功能需求

> 本文是 PC 客户端按指定设计稿实现的产品需求与验收基线，不代表现有功能已经完成。视觉与页面范围以[PC 对话与云端电脑设计稿](<设计图/Morde-PC对话与云端电脑设计稿.html>)为准；普通用户功能由 `morde-pc` 客户端承载，不交付独立普通用户 Web 端。设计稿中的示例内容只用于表达布局，不代表真实数据或已接通的操作。

## 目标与范围

在 `morde-pc` 中按设计稿逐页实现外观、导航和真实交互：以对话为中心，在同一窗口中查找会话、查看任务，并打开与当前工作有关的云端电脑或文件。按 Morde 品牌和平台习惯适配尺寸与系统窗口；复用现有客户端、服务端及本机能力，不另建普通用户 Web 产品。

本需求覆盖设计稿中的全部页面、子页、侧边栏标签、表单和可见操作，并要求设计稿未展示的既有 PC 功能继续有可达入口。普通用户 Web 和管理后台不在本次实现范围；iOS 不照搬 PC 布局，但与 PC 共用的会话、任务和个人数据遵循现有跨端规则。设计稿未定义的业务字段、权限与服务行为沿用项目现有合同，不凭空新增；品牌标志沿用 `images/morde-logo-reference.png`。

## 页面结构

```text
┌──────┬──────────────┬──────────────────────────┬────────────────────────┐
│ 导航 │ 会话         │ 当前对话                 │ 会话侧边栏            │
│      │ 主会话       │ 消息、回复与必要进展     │ 任务 / 电脑 / 文件     │
│      │ 旁聊（＋）   │                          │ 可切换、关闭或放大     │
│      │ 旁聊列表     │ 输入框与发送             │                        │
└──────┴──────────────┴──────────────────────────┴────────────────────────┘
```

上图表达区域关系，不限定像素尺寸。左侧导航、会话列表和右侧工作区可按窗口空间展开或收起；收起后入口仍可找到。关闭右侧工作区后，对话使用释放出的空间。

| 区域 | 功能与规则 |
| --- | --- |
| 窗口顶部 | 参考 Codex，将后退、前进、左侧栏收起／展开及会话侧边栏标签和操作集中在顶部，不显示页面或会话标题标签。左侧栏按钮在对话页控制会话列表，在非对话页控制当前页面子菜单；收起后可从同一位置重新展开。放大会话工作区时也可从顶部重新展开会话列表，不改变电脑控制权。后退和前进按实际访问历史切换页面或会话工作区，不能返回时对应按钮禁用；切换不丢失草稿或改变电脑控制权。 |
| 左侧导航 | 提供对话、个人数据、目标与计划以及设置与授权入口；模型与工具、云端电脑管理、客户端、API Key 和账户设置归入设置与授权。电脑画面、任务和会话文件由右侧会话侧边栏承载，不在左侧导航重复设置入口。图标可通过悬停或聚焦识别名称。 |
| 会话侧栏 | 从上到下依次展示唯一的主会话和旁聊。旁聊分组可展开、收起，标题旁的“＋”用于新建旁聊；主会话与旁聊均可切换。旁聊较多时分页，搜索在所有旁聊中查找并更新分页。整个会话侧栏可收起，并通过窗口顶部的按钮重新展开。不展示项目或最近分组。 |
| 页面子菜单 | 非对话页面在左侧导航旁显示当前页面的纵向分类菜单，与会话侧栏的位置、宽度及标题和菜单项起始位置对齐；设置、个人数据、目标与计划分别展示自己的分类及选中状态，切换分类只更换右侧内容。子菜单可从顶部收起或展开，收起时右侧内容使用释放出的空间。 |
| 对话区 | 显示当前会话的消息、自然语言回复、必要的进展及真实发送状态。历史消息按可用空间分页，超长消息也能分段完整阅读；阅读历史时收到新消息不强制切到最新页。输入框和发送按钮保持可用；长消息、长文件名和面板展开不得遮挡它们。对话区不再单独放置“任务动态”和“云端电脑”按钮。 |
| 会话侧边栏 | 在对话右侧统一承载当前会话的任务动态、云端电脑以及相关文件或产物。参考 Codex，在窗口顶栏展示已打开内容的标签，可切换、关闭及通过“＋”打开内容；面板内不重复显示标签标题、说明和“返回对话”按钮。需要专注操作时可放大，退出放大后回到原来的对话和面板。侧边栏收起时，窗口右上角显示打开侧边栏按钮；展开后该按钮隐藏，由侧边栏顶栏提供收起操作。 |

个人数据、目标与计划、设置与授权等非对话页面保留统一的 PC 导航，不显示会话列表、对话内容、会话侧边栏及其开关，也不放置“返回对话”按钮；用户通过导航中的对话入口切回原会话，草稿保持不变。切换页面、会话或面板不丢失已保存的消息，也不丢弃尚未发送的输入。会话相关面板由当前所选会话确定归属，无需在每张卡片上重复会话名；切换会话时不能把原会话的任务、文件或结果显示成新会话的内容。

macOS 桌面端在顶部左侧预留系统窗口控制，再依次放置导航和左侧栏控制；Windows 桌面端在顶部右侧预留原生最小化、最大化／还原和关闭区域，导航与标签不得遮挡系统控制。两种窗口均保留可拖动区域，按钮保持可点击；客户端内容区不绘制伪系统窗口按钮。设计稿里的窗口预览控件只用于说明两种平台外观，不进入产品。

## 设计稿逐页逐功能清单

下表覆盖设计稿里的每个页面区域、子页和可见操作。示例账号、模型、消息、任务、文件、状态和日期均须替换为当前账号的真实数据。原型中的“窗口预览”“设计预览”“状态切换”和仅弹出演示提示的按钮不是产品功能；对应业务操作必须接入现有服务或 PC 本机能力，暂不支持时说明原因并禁用，不得显示成功或留下无响应按钮。

| 页面／区域 | 必须提供的功能 | 主要验收结果 |
| --- | --- | --- |
| PC 窗口与全局导航 | 使用 Morde 蓝色 M 标识；macOS / Windows 使用原生窗口控制；顶栏后退、前进、左栏收起/展开；导航进入对话、审核、个人数据、目标与计划、设置；账户入口与待处理提示可达。 | 两种桌面系统中窗口按钮、拖动区域和页面操作不重叠；历史无记录时后退/前进禁用；切页后能回到原会话和草稿。 |
| 对话与会话列表 | 显示主会话和旁聊；搜索、折叠旁聊、新建旁聊、切换会话；按当前账号读取历史和状态。 | 新建、搜索和切换结果正确；每个会话的消息、任务、文件、草稿和阅读位置不串线。 |
| 对话消息与输入区 | 展示真实消息、回复、任务进度、审批卡片、附件；输入文字、选择可用模型、添加附件、语音输入（设备能力可用时）、发送；Enter 发送、Shift+Enter 换行。 | 发送中、成功、失败、等待和结果未知有真实状态；重连或重试不重复受理已确认请求；附件和模型选择只作用于对应请求。 |
| 消息反馈与发送失败 | 已成功发送/接收的消息不显示“重新”或“编辑”按钮。用户消息发送失败时，才在消息框左侧紧邻气泡显示红色感叹号；点击只重发该条失败消息。消息反馈表情放在消息框右下角，允许下半部略微超出气泡。 | 成功、发送中、等待确认及 AI 回复均无重发/编辑按钮；只有明确失败时出现感叹号，位置贴近用户气泡左侧且不跑到整行最左边；重发不会创建重复消息。 |
| 审核事项 | 左侧显示待处理提示；列出请求来源、所需权限、影响和任务；批准、拒绝及查看处理结果。 | 操作绑定原审批和任务；过期、权限变化、已在另一端处理或结果未知时按服务端状态刷新，不重复执行或误报成功。 |
| 个人资料 | 查看和编辑名称、头像、简介及现有资料字段，保存到账号数据。 | 服务端确认后显示已保存；失败时保留草稿；另一端获得最新已确认数据。 |
| AI 个性 | 查看、编辑对话偏好，保存或按现有能力恢复默认。 | 显示当前真实值；保存/恢复的结果与服务端一致，失败保留未提交内容。 |
| 记忆 | 查看、添加、编辑、删除记忆；控制个人记忆是否允许 AI 使用。 | 每项变更有授权校验和真实结果；关闭使用开关后后续个人对话不读取已保存记忆。 |
| 资源库 | 查看个人文件、上传状态和空间；按现有能力添加、打开或删除文件。 | 权限、大小、上传进度、失败和删除结果准确；文件只传至用户明确授权的 Morde 功能目标。 |
| 目标 | 查看、新建、编辑、更新进展、暂停或完成目标。 | 操作更新对应目标；空状态与服务端一致，保存失败不丢草稿。 |
| 定时计划 | 新建、编辑、启停计划；设置内容、周期、时区、运行时间、模型、预算、错过策略、通知；查看版本与运行记录。 | 对时间、时区、周期和预算校验；计划目标遵循现有默认电脑与授权规则；每次执行可追踪真实状态。 |
| 模型与工具：个人模型 | 浏览个人连接；按服务预设或自定义添加、编辑模型名、显示名、HTTPS 服务地址、上下文窗口和 API 密钥；保存、检查文本/工具/视觉/流式能力。 | 密钥保存后不回显；编辑密钥留空表示保留原值；能力状态来自实际检查。模型保存错误保留表单内容并展示可理解的服务端原因；字段缺失/格式错误标到对应字段。若保存成功但连接检查失败，应显示“已保存、连接未通过”，不能混成保存失败。 |
| 模型与工具：团队模型 | 查看团队提供的模型、状态和能力详情；仅在实际权限允许时使用。 | 普通成员不能编辑管理员配置；不可用模型不出现在可选项或显示不可用原因。 |
| 模型与工具：MCP 工具 | 浏览连接；添加、编辑、授权/凭据、启用/停用、删除；按模板选择 OAuth 或服务端允许的凭据方式。 | 密钥和令牌不可回显；地址变更时按安全规则处理旧凭据；工具变更只影响后续任务，权限和服务端允许列表有效。 |
| 云端电脑管理 | 查看我的电脑和共享电脑；查看状态、规格、到期和权限；创建、打开、文件/版本、续期、共享、释放/恢复、复制或删除（按权限和状态开放）。 | 每个动作对应选中的电脑并经服务端确认；破坏性动作先说明影响并确认；共享电脑权限不足时不提供操作。 |
| 本机文件夹同步 | 选择本机目录、确认项目名/范围/默认云端目标后手动开始；显示进行中、完成、待处理、失败；查看并处理冲突。 | 只在用户点击后单向同步到固定目标；冲突、授权失效、根目录不可访问或结果未知时保留文件、不误报完成，遵守项目 AGENTS.md 的完整同步边界。 |
| 客户端与设备 | 查看当前/已登录设备、授权有效期和详情；按权限撤销授权或进入客户端获取/更新流程。 | 撤权状态与服务端一致；说明其影响范围，不删除本机文件；版本/下载来源有效。 |
| API Key | 创建名称和有效期、查看 MCP 服务地址、复制地址、撤销密钥。 | 新密钥仅创建时显示一次；列表只显示掩码和状态；复制/撤销有反馈，过期或撤销后不能继续授权调用。 |
| 账户与安全 | 查看账号和登录状态；修改密码、打开设备管理、管理隐私/记录同意与额度、退出账号。 | 身份校验、退出及隐私操作接入现有服务；权限和记录状态真实显示；失败时提供恢复路径。 |
| 会话侧栏：云端电脑 | 当前会话打开真实桌面；展示连接和控制权；按能力打开浏览器、终端、文件管理器、VS Code；接管/交还、放大/退出放大、共享说明。 | 仅展示指定且授权的电脑；控制权在服务端确认前不切换；断线可恢复；关闭标签不会停止任务或偷偷交还控制权。 |
| 会话侧栏：任务动态/详情 | 当前会话任务列表、状态/进度/更新时间；打开详情、工作过程、审批、补充、暂停/继续/停止（依任务状态开放）。 | 不提供跨会话混合任务；按钮随任务真实状态变化；用户切换会话或离线重连不取消/重复执行任务。 |
| 会话侧栏：文件与文档 | 查看当前会话文件和产物；打开文档阅读或编辑；查看同步来源与状态；在授权范围内保存或继续同步。 | 文件归属和版本正确；编辑草稿不因切换标签丢失；不可访问、冲突和保存失败明确提示。 |
| 页面恢复错误 | 对整页加载失败提供重试和返回；局部失败在对应区域提示并保留其他可用页面。 | 不显示白屏、原始 JSON 或虚构空列表；重试不循环，返回路径不可用时提供 PC 内明确入口。 |

### 设计稿未展示但 PC 必须保留的既有功能

实现以设计稿重排入口，不因截图未画出而删除 PC 现有业务能力或数据。实施前盘点当前客户端及其授权可见的登录/注册/密码、通知、项目与 Codex 会话、云端电脑创建和详情、工作台（桌面、终端、Workspace、主机文件、VS Code）、文件版本、设备授权和旧链接等功能；逐项映射到设计稿页面、账户入口或兼容页面。不能在 PC 内保留的入口必须给出可达替代路径和迁移提示。管理后台继续作为独立管理员产品。

### 推荐的落地办法

先固定本设计稿版本和当前 PC 客户端基线，再按上表给每个页面/动作记录现状入口、数据来源/API 或本机能力、权限、加载/空/错误/离线状态及缺口。实现时按依赖顺序先完成共用窗口和导航，再完成会话/任务/审核/工作区，再完成个人数据/目标/设置，最后核对未在设计稿展示的既有页面与回归。每一项只有在真实 `morde-pc` 中从用户入口操作成功并检查异常恢复后才算交付；本地 mock 只能验证界面路径，不能证明真实服务或电脑能力已接通。对服务合同缺失、权限不清或设计稿未说明的行为，先沿用现行业务规则并记录问题，不用演示数据补齐。

## 设置、个人数据与目标计划

非对话页面的分类菜单统一放在左侧，不与会话列表同时显示；菜单展开时不在内容区重复显示当前分类标题，收起后保留必要的内容标题以识别位置。区分不同内容所需的分组标题、表单字段名称和操作提示保留，按钮文字不重复当前分类名。各页面及会话侧边栏不要求用户拖动上下滚动条：卡片和空状态紧凑排布，优先在一屏呈现；内容超出窗口时以明确的上一页、下一页和页码访问。列表随窗口空间分页，筛选、搜索、切换会话或增删后页码与结果保持一致，不漏项或重复。长表单、任务详情和文档可分步或分页，所有字段、内容、保存及取消操作仍可访问，翻页不丢失输入；常用操作在空间允许时与内容并排，窄窗口可换行且保持可读。

- **模型与工具：** 保留我的模型、团队模型和 MCP 工具连接列表。模型显示来源、密钥配置状态、服务、上下文窗口和真实能力检查结果；个人模型可添加、编辑和检查连接，团队模型按权限只读。新增或编辑保留服务预设、模型名、窗口、HTTPS 地址和密钥字段；已保存密钥不回显，编辑留空保留原值。MCP 连接保留添加、编辑、授权和凭据、启停与删除等入口，按实际状态和权限展示；检查可能产生服务商用量时说明。
- **云端电脑管理：** 设置页同时展示我的电脑与共享给我的电脑，以及创建、状态、规格、到期和权限；常用的打开、文件与版本、续期清楚可见，其他管理操作可收入更多菜单。释放、恢复、复制、删除及共享按实际状态、权限和确认规则处理。电脑画面仍在对应会话侧栏打开。
- **个人数据：** 保留个人资料、AI 个性、记忆、动态、灵感、资源库和偏好分类。用户保存或修改后，服务端确认成功即更新当前账号的云端数据，不提供个人数据同步开关或“立即同步”按钮；同账号手机端连接、重连时自动获取最新已确认的数据，在线期间云端数据变化后也自动更新。保存失败、离线或跨端发生冲突时保留未提交的草稿并提示处理，不把未确认的修改显示为已保存，也不覆盖另一端未提交的草稿。分类内的编辑、记忆和附件操作继续遵守现有授权与账号隔离。
- **目标与计划：** 目标和定时计划通过左侧子菜单分别呈现，保留创建、查看和管理入口；目标支持编辑和状态更新，计划支持启停、版本与运行记录。创建计划时按现有规则选择模型、可选电脑、触发时间、时区、预算与通知。

## 对话和任务

- 普通聊天直接获得自然回复，例如讲笑话或询问时间，无需选择云端电脑，也不因为发送一条普通消息就创建任务。回答时间时使用可信的时间及其时区；无法确定时如实说明。简单问题可按需使用工具。
- 需要执行的工作按实际情况显示任务动态。任务侧栏只展示当前会话的任务，不提供“全部任务 / 当前会话”切换；切换会话时同步切换任务、待处理标记和详情。任务的进度、审批、澄清、结果、暂停和停止等操作始终对应正确的任务和会话。待处理事项在面板收起时仍有可辨认的入口。
- 任务执行期间仍可继续对话。新消息与既有任务有关、无关或关联不明时，按现行主助手规则处理；不得因切换会话、关闭面板或短暂断网而误取消任务、重复执行已确认操作或虚报完成。
- 模型、电脑、文件和附件的选择显示实际状态。更改输入区的选择只影响后续适用的请求，不迁移已受理的任务；无电脑时普通文字对话仍可使用。

## 云端电脑

1. 云端电脑在当前会话工作区内以远程画面为主体，使用可用区域居中并尽量铺满，不再用蓝色品牌预览卡包住远程画面。保留 Morde PC 顶栏、会话和对话布局；本次只调整云端电脑控制区。
2. 控制区底部只放四个功能入口：远程桌面、终端、文件、VS Code。点击入口在同一控制区切换功能，不打开额外窗口或独立页面。当前账号尚未取得有效接管租约时四个入口保持禁用；服务端确认当前用户已接管后才可使用。Workspace 不作为第五个底部入口；如仍需访问，归入文件能力的既有授权路径，不删除其数据或服务能力。
3. 云端电脑控制区只额外提供一个控制权按钮：AI 控制时显示“接管电脑”，当前用户有效接管时显示“交还 AI”。接管或交还进行中按钮显示真实进度并禁用；状态未确认、租约失效或由他人控制时不能显示为当前用户已接管。主画面不再显示单独的控制权状态胶囊、重复的主机状态栏、续期、适应窗口、键盘、Alt+Tab、找回窗口、全屏或独立重试等按钮。PC 外壳原有的标签、放大和系统窗口操作不属于云端控制区，不因本条删除。
4. 主机运行状态与远程桌面连接状态分开判断。“运行中”不等于远程桌面已连接；只有收到真实远程桌面连接状态后才显示桌面已连接。连接等待时在画面区域显示居中的加载状态，不使用断线黑屏样式。
5. 远程桌面确实无法连接或连接中断时，仅将远程画面区域切换为深色／黑色，并在中央显示简洁错误信息；Morde PC 外壳、底部四个功能入口和唯一的接管／交还按钮保持可见。错误状态不使用白色整页错误卡，也不叠加另一组恢复按钮；连接恢复由现有自动恢复或重新选择远程桌面入口触发。终端、文件或 VS Code 的局部错误只影响当前功能区域，不把整个控制界面变黑。
6. 票据、权限、控制权或工作台页面加载失败必须与远程桌面传输失败区分，显示对应的局部错误；不能仅凭 Host 状态或 iframe 已加载就声称桌面已连接。所有可操作入口继续遵循现有账号、Host、共享权限及有效租约校验，不得因视觉调整放宽权限。
7. 打开、关闭或切换面板本身不创建或停止任务，也不自动交还控制权；电脑或权限不可用时说明原因，不自动切换到其他电脑或声称操作成功。

本机文件夹同步入口应显示实际目标电脑与同步状态，并遵守现行规则：由用户在 PC 明确点击触发，内容从本机单向同步到指定云端电脑；后续本机变更需再次点击，云端变更不反向修改本机。冲突、目录不可访问或授权失效时应提示，不能显示为完成。

## 输入、异常与可用性

- PC 客户端内的可编辑输入框支持系统粘贴，包括对话、搜索、表单、密码和 API 密钥输入；普通文本可按系统习惯选择、复制、剪切和全选，键盘快捷键与右键操作可用。密码和密钥不因粘贴而暴露到不应显示的位置。远程电脑内的输入仍受该电脑的控制和剪贴板权限约束。
- 局部接口失败时，在受影响的区域说明情况并提供适用的重试；其他可用内容、导航和输入继续可用。加载失败、权限不足、网络中断和结果未知应分别表达，不把未确认的数据显示为空或成功。
- 页面确实无法显示时，使用统一的可读错误页面，提供重试和返回按钮；没有可用历史时提供回到 PC 首页或云端电脑列表的入口。错误恢复不能依赖出错的同一接口，不能反复跳转到错误页、白屏或原始 JSON。
- 控件文字简洁，状态不能只靠颜色区分；图标按钮有可访问名称和可见键盘焦点。常用操作直接可见，低频信息按需展示，避免同时出现多个含义相同的按钮或标签。

## 验收条件

1. 在 1440×900 窗口中，导航、会话列表、对话和已打开的右侧电脑面板可同时使用；在 1024×768、800×600 窗口中，可通过收起或切换侧栏完成相同操作。各页面及侧栏不需要上下拖动滚动条；超出空间的内容可通过分页完整访问，消息、输入框、发送按钮和面板操作不互相遮挡。
2. 会话侧栏依次显示一个主会话和旁聊分组，没有项目或最近分组；通过旁聊标题旁的“＋”新建并切换至少两个旁聊，历史与草稿归属正确。旁聊分组和整个会话侧栏均可收起、重新展开。进入个人数据、目标与计划、设置等非对话页面时，会话相关区域、开关和“返回对话”按钮均不显示；通过对话导航可继续原会话和草稿。侧边栏面板内没有重复标题、说明或“返回对话”按钮；任务列表无范围切换，切换会话后只显示该会话的任务及待处理标记。右侧边栏顶栏标签可添加、切换和关闭；收起后右上角显示打开按钮，重新展开后该按钮隐藏。不同会话的任务和结果不混淆。
3. 在真实 `morde-pc` 中打开指定云端电脑：远程画面居中并填充控制区；底部只有远程桌面、终端、文件、VS Code 四个功能入口，另有一个接管／交还按钮。未接管时四个入口均不可点击；服务端确认当前用户取得有效租约后全部可用，交还或租约失效后重新禁用。控制区不显示独立的主机状态胶囊、续期、键盘、Alt+Tab、找回窗口、全屏或重试按钮，PC 外壳自身的标签和系统窗口操作仍可用。
4. 分别验证远程桌面连接中、连接成功、连接超时和连接中断：连接中显示居中加载状态；只有远程桌面确实无法连接或已中断时，画面区域变为黑色并在中央显示错误，PC 外壳和底部控制入口仍可见。Host 显示运行中但 noVNC 未连通时不得显示“已连接”；票据、权限或工作台加载错误不误显示为远程桌面断线。
5. 输入“讲个笑话”和“现在几点”，可收到自然回复且不要求电脑，不新增执行任务；时间无法确认时明确说明。真实执行任务仍可在侧栏查看和处理，关闭面板不会停止它。
6. 在对话框、普通表单及 API 密钥框用系统快捷键和右键菜单粘贴文本；在普通文本框复制、剪切和全选。输入法组合文字、已有内容和焦点不因侧栏切换而丢失。
7. 分别让任务列表、电脑连接和页面加载失败：相关位置显示可理解的错误及可用恢复入口；对话草稿和其他可用区域保留，返回和重试不陷入循环，也不显示原始 JSON。
8. 电脑文件同步的目标、进行中、完成、待处理和失败状态与实际结果一致；未再次点击同步前，本机新增、修改和删除不会自动应用到云端。
9. 设置、个人数据及目标与计划的分类均位于左侧子菜单，切换后显示对应内容与选中状态；对话仍使用原会话侧栏。设置页能找到个人与团队模型列表、MCP 工具以及云端电脑管理；个人数据的七个分类和目标、定时计划可访问，现有操作与权限没有因布局调整而消失。个人密钥不回显；电脑管理与任务控制显示服务端确认的真实状态。
10. 构造超过一屏的旁聊、任务、模型或电脑列表，能前后翻页并访问全部条目；搜索、筛选及数量变化后页码有效。长消息、长表单、任务详情和文档均可完整阅读或编辑，翻页不丢失输入；查看历史期间收到新消息不会强制切页。
11. PC 上修改并保存个人数据，服务端确认后云端即为新版本；同账号手机连接或重连后自动看到最新已确认内容，在线期间也能自动获得其他端已保存的更新。个人数据页面没有手动同步按钮或同步开关；保存失败、离线和跨端冲突时保留草稿并如实提示。
12. macOS 与 Windows 的窗口顶部均能找到页面后退、前进和当前左侧栏的收起／展开控制，不显示页面或会话标题标签；非对话页的按钮控制页面子菜单，不显示会话列表或右侧会话侧边栏。各窗口宽度下页面子菜单与会话侧栏位置和宽度对齐。放大电脑后仍能从顶部展开会话列表，且不改变控制权。窗口控制分别位于系统习惯的位置，与标签和操作不重叠。后退、前进切换页面或工作区后，草稿及电脑控制权保持正确；无对应历史时按钮不可用。
13. 模型配置提交必填缺失或格式错误时，错误定位到对应字段；保存接口失败时保留表单并说明原因。分别模拟“保存失败”和“保存成功但连接检查失败”，确认二者在界面上可区分，密钥不回显或写入日志。
14. 验证成功消息没有“重新/编辑”按钮；只对明确发送失败的用户消息显示红色感叹号，且按钮紧贴气泡左侧；点击后只重试原消息。验证消息表情位于气泡右下角并部分越出下边缘，不遮挡消息内容。
15. 设计稿中的每页/子页、侧栏标签及可见操作均在真实 `morde-pc` 中从入口验收；逐项记录真实服务/设备与本地模拟的区别。浏览器预览、截图相似或构建成功不能替代 PC 客户端验收。
