# Morde PC 端布局与云端电脑体验需求

> 需求稿，描述目标体验，不代表现有功能已经完成。参考本次对话中的 Codex 截图：左侧导航与会话列表、中间对话、右侧会话工作区，以及简洁的电脑画面和控制权提示。

## 目标与范围

PC 客户端和 PC 用户网页采用一致的布局：以对话为中心，在同一窗口中查找会话、查看任务，并打开与当前工作有关的云端电脑或文件。整体结构和交互接近参考图，尺寸、图标和细节可按 Morde 的品牌与功能调整。

本需求覆盖 PC 用户端的导航、助手对话、任务动态、云端电脑、模型与工具设置、个人数据和目标计划。手机端和管理后台的界面不在本次布局调整范围内；个人数据的跨端读取遵循下述规则。本文更新布局与交互目标；消息、任务、电脑授权等业务规则继续遵守项目现行约定。品牌标志沿用现有 Morde Logo。

## 页面结构

```text
┌──────┬──────────────┬──────────────────────────┬────────────────────────┐
│ 导航 │ 会话         │ 当前对话                 │ 会话侧边栏            │
│      │ 主会话       │ 消息、回复与必要进展     │ 任务 / 电脑 / 文件     │
│      │ 旁聊（＋）   │                          │ 可切换、关闭或放大     │
│      │ 旁聊列表     │ 输入框与发送             │                        │
└──────┴──────────────┴──────────────────────────┴────────────────────────┘
```

上图表达区域关系，不限定像素尺寸。左侧导航、会话列表和右侧工作区可按窗口空间展开或收起；收起后入口仍可找到。关闭右侧工作区后，对话使用释放出的空间。

| 区域 | 功能与规则 |
| --- | --- |
| 窗口顶部 | 参考 Codex，将后退、前进、左侧栏收起／展开及会话侧边栏标签和操作集中在顶部，不显示页面或会话标题标签。左侧栏按钮在对话页控制会话列表，在非对话页控制当前页面子菜单；收起后可从同一位置重新展开。放大会话工作区时也可从顶部重新展开会话列表，不改变电脑控制权。后退和前进按实际访问历史切换页面或会话工作区，不能返回时对应按钮禁用；切换不丢失草稿或改变电脑控制权。 |
| 左侧导航 | 提供对话、个人数据、目标与计划以及设置与授权入口；模型与工具、云端电脑管理、客户端、API Key 和账户设置归入设置与授权。电脑画面、任务和会话文件由右侧会话侧边栏承载，不在左侧导航重复设置入口。图标可通过悬停或聚焦识别名称。 |
| 会话侧栏 | 从上到下依次展示唯一的主会话和旁聊。旁聊分组可展开、收起，标题旁的“＋”用于新建旁聊；主会话与旁聊均可切换。旁聊较多时分页，搜索在所有旁聊中查找并更新分页。整个会话侧栏可收起，并通过窗口顶部的按钮重新展开。不展示项目或最近分组。 |
| 页面子菜单 | 非对话页面在左侧导航旁显示当前页面的纵向分类菜单，与会话侧栏的位置、宽度及标题和菜单项起始位置对齐；设置、个人数据、目标与计划分别展示自己的分类及选中状态，切换分类只更换右侧内容。子菜单可从顶部收起或展开，收起时右侧内容使用释放出的空间。 |
| 对话区 | 显示当前会话的消息、自然语言回复、必要的进展及真实发送状态。历史消息按可用空间分页，超长消息也能分段完整阅读；阅读历史时收到新消息不强制切到最新页。输入框和发送按钮保持可用；长消息、长文件名和面板展开不得遮挡它们。对话区不再单独放置“任务动态”和“云端电脑”按钮。 |
| 会话侧边栏 | 在对话右侧统一承载当前会话的任务动态、云端电脑以及相关文件或产物。参考 Codex，在窗口顶栏展示已打开内容的标签，可切换、关闭及通过“＋”打开内容；面板内不重复显示标签标题、说明和“返回对话”按钮。需要专注操作时可放大，退出放大后回到原来的对话和面板。侧边栏收起时，窗口右上角显示打开侧边栏按钮；展开后该按钮隐藏，由侧边栏顶栏提供收起操作。 |

个人数据、目标与计划、设置与授权等非对话页面保留统一的 PC 导航，不显示会话列表、对话内容、会话侧边栏及其开关，也不放置“返回对话”按钮；用户通过导航中的对话入口切回原会话，草稿保持不变。切换页面、会话或面板不丢失已保存的消息，也不丢弃尚未发送的输入。会话相关面板由当前所选会话确定归属，无需在每张卡片上重复会话名；切换会话时不能把原会话的任务、文件或结果显示成新会话的内容。

macOS 桌面端在顶部左侧预留系统窗口控制，再依次放置导航和左侧栏控制；Windows 桌面端在顶部右侧预留原生最小化、最大化／还原和关闭区域，导航与标签不得遮挡系统控制。两种窗口均保留可拖动区域，按钮保持可点击；PC 网页使用浏览器提供的窗口控制，不在页面中重复绘制。设计预览可切换两种窗口外观，系统控制的位置仅作示意。

## 设置、个人数据与目标计划

非对话页面的分类菜单统一放在左侧，不与会话列表同时显示；菜单展开时不在内容区重复显示当前分类标题，收起后保留必要的内容标题以识别位置。区分不同内容所需的分组标题、表单字段名称和操作提示保留，按钮文字不重复当前分类名。各页面及会话侧边栏不要求用户拖动上下滚动条：卡片和空状态紧凑排布，优先在一屏呈现；内容超出窗口时以明确的上一页、下一页和页码访问。列表随窗口空间分页，筛选、搜索、切换会话或增删后页码与结果保持一致，不漏项或重复。长表单、任务详情和文档可分步或分页，所有字段、内容、保存及取消操作仍可访问，翻页不丢失输入；常用操作在空间允许时与内容并排，窄窗口可换行且保持可读。

- **模型与工具：** 保留我的模型、团队模型和 MCP 工具连接列表。模型显示来源、密钥配置状态、服务、上下文窗口和真实能力检查结果；个人模型可添加、编辑和检查连接，团队模型按权限只读。新增或编辑保留服务预设、模型名、窗口、HTTPS 地址和密钥字段；已保存密钥不回显，编辑留空保留原值。MCP 连接保留添加、编辑、授权和凭据、启停与删除等入口，按实际状态和权限展示；检查可能产生服务商用量时说明。
- **云端电脑管理：** 设置页同时展示我的电脑与共享给我的电脑，以及创建、状态、规格、到期和权限；常用的打开、文件与版本、续期清楚可见，其他管理操作可收入更多菜单。释放、恢复、复制、删除及共享按实际状态、权限和确认规则处理。电脑画面仍在对应会话侧栏打开。
- **个人数据：** 保留个人资料、AI 个性、记忆、动态、灵感、资源库和偏好分类。用户保存或修改后，服务端确认成功即更新当前账号的云端数据，不提供个人数据同步开关或“立即同步”按钮；同账号手机端连接、重连时自动获取最新已确认的数据，在线期间云端数据变化后也自动更新。保存失败、离线或跨端发生冲突时保留未提交的草稿并提示处理，不把未确认的修改显示为已保存，也不覆盖另一端未提交的草稿。分类内的编辑、记忆和附件操作继续遵守现有授权与账号隔离。
- **目标与计划：** 目标和定时计划通过左侧子菜单分别呈现，保留创建、查看和管理入口；目标支持编辑和状态更新，计划支持启停、版本与运行记录。创建计划时按现有规则选择模型、可选电脑、触发时间、时区、预算与通知。

## 对话和任务

- 普通聊天直接获得自然回复，例如讲笑话或询问时间，无需选择云端电脑，也不因为发送一条普通消息就创建任务。回答时间时使用可信的时间及其时区；无法确定时如实说明。简单问题可按需使用工具。
- 需要执行的工作按实际情况显示任务动态。任务侧栏只展示当前会话的任务，不提供“全部任务 / 当前会话”切换；切换会话时同步切换任务、待处理标记和详情。任务的进度、审批、澄清、结果、暂停和停止等操作始终对应正确的任务和会话。待处理事项在面板收起时仍有可辨认的入口。
- 任务执行期间仍可继续对话。新消息与既有任务有关、无关或关联不明时，按现行主助手规则处理；不得因切换会话、关闭面板或短暂断网而误取消任务、重复执行已确认操作或虚报完成。
- 模型、电脑、文件和附件的选择显示实际状态。更改输入区的选择只影响后续适用的请求，不迁移已受理的任务；无电脑时普通文字对话仍可使用。

## 云端电脑

1. 从对话或云端电脑入口打开指定电脑时，在会话工作区中显示真实桌面，并保留对话和 PC 导航。用户可切换到其他已打开的会话内容；从对话打开时，关闭电脑面板回到原对话。直接打开独立电脑窗口时，应提供同一 PC 导航的入口和明确的返回按钮：有来源时返回来源，无可返回历史时回到 PC 云端电脑列表。放大或全屏后仍能退出并返回。
2. 电脑面板突出电脑名称、连接状态、当前控制权和画面。桌面随面板大小适配；连接中、断开或失败时显示真实状态及可用的重试或返回操作。接口失败不能将用户带到原始 JSON 页面。
3. 根据实际控制状态提供“接管电脑”或“交还 AI”。服务端确认当前用户成功接管后，自动放大会话侧边栏和电脑画面，方便操作，并保留顶栏导航和退出放大入口；交还成功后，若用户未手动调整，则恢复接管前的布局。接管、交还进行中和失败时显示真实结果；服务端确认前不显示控制权已切换，也不将桌面应用显示为可操作。AI 持有控制权不等于 AI 正在操作，只有有实际操作信息时才这样提示；他人持有控制权、只读和租约失效也要能区分。
4. 电脑画面底部提供浏览器、终端、文件管理器和 VS Code 等与现有 AIO Sandbox 能力一致的快捷入口；按目标电脑实际可用状态、控制权和授权提供操作，不可用时说明原因。终端、主机文件、Workspace、VS Code、续期及窗口相关操作保留在与电脑有关的侧栏或详情中，其中 Workspace 和主机文件是不同视图。重复入口、控制版本等日常不需要的技术标签不占据主画面；需要诊断时仍可找到相关信息。桌面可能向获准成员展示文件的提示应可查看。
5. 打开、关闭或切换面板本身不创建或停止任务，也不声称控制权已经交还。电脑或权限不可用时说明原因，不自动切换到其他电脑或声称操作成功。

本机文件夹同步入口应显示实际目标电脑与同步状态，并遵守现行规则：由用户在 PC 明确点击触发，内容从本机单向同步到指定云端电脑；后续本机变更需再次点击，云端变更不反向修改本机。冲突、目录不可访问或授权失效时应提示，不能显示为完成。

## 输入、异常与可用性

- PC 客户端和 PC 网页的可编辑输入框都支持系统粘贴，包括对话、搜索、表单、密码和 API 密钥输入；普通文本可按系统习惯选择、复制、剪切和全选，键盘快捷键与右键操作可用。密码和密钥不因粘贴而暴露到不应显示的位置。远程电脑内的输入仍受该电脑的控制和剪贴板权限约束。
- 局部接口失败时，在受影响的区域说明情况并提供适用的重试；其他可用内容、导航和输入继续可用。加载失败、权限不足、网络中断和结果未知应分别表达，不把未确认的数据显示为空或成功。
- 页面确实无法显示时，使用统一的可读错误页面，提供重试和返回按钮；没有可用历史时提供回到 PC 首页或云端电脑列表的入口。错误恢复不能依赖出错的同一接口，不能反复跳转到错误页、白屏或原始 JSON。
- 控件文字简洁，状态不能只靠颜色区分；图标按钮有可访问名称和可见键盘焦点。常用操作直接可见，低频信息按需展示，避免同时出现多个含义相同的按钮或标签。

## 验收条件

1. 在 1440×900 窗口中，导航、会话列表、对话和已打开的右侧电脑面板可同时使用；在 1024×768、800×600 窗口中，可通过收起或切换侧栏完成相同操作。各页面及侧栏不需要上下拖动滚动条；超出空间的内容可通过分页完整访问，消息、输入框、发送按钮和面板操作不互相遮挡。
2. 会话侧栏依次显示一个主会话和旁聊分组，没有项目或最近分组；通过旁聊标题旁的“＋”新建并切换至少两个旁聊，历史与草稿归属正确。旁聊分组和整个会话侧栏均可收起、重新展开。进入个人数据、目标与计划、设置等非对话页面时，会话相关区域、开关和“返回对话”按钮均不显示；通过对话导航可继续原会话和草稿。侧边栏面板内没有重复标题、说明或“返回对话”按钮；任务列表无范围切换，切换会话后只显示该会话的任务及待处理标记。右侧边栏顶栏标签可添加、切换和关闭；收起后右上角显示打开按钮，重新展开后该按钮隐藏。不同会话的任务和结果不混淆。
3. 在对话中打开指定云端电脑，能看到真实连接和控制状态；接管成功后电脑画面自动放大，可手动退出放大，交还成功后按上述规则恢复原布局。浏览器、终端、文件管理器和 VS Code 快捷入口按实际权限和可用状态工作。接管、交还、失败和断开均与服务端确认一致。AI 仅持有控制权但没有操作时，不显示“正在操作”。关闭面板返回对话，全屏可退出；独立窗口即使没有历史也能返回云端电脑列表。
4. 输入“讲个笑话”和“现在几点”，可收到自然回复且不要求电脑，不新增执行任务；时间无法确认时明确说明。真实执行任务仍可在侧栏查看和处理，关闭面板不会停止它。
5. 在对话框、普通表单及 API 密钥框用系统快捷键和右键菜单粘贴文本；在普通文本框复制、剪切和全选。输入法组合文字、已有内容和焦点不因侧栏切换而丢失。
6. 分别让任务列表、电脑连接和页面加载失败：相关位置显示可理解的错误及可用恢复入口；对话草稿和其他可用区域保留，返回和重试不陷入循环，也不显示原始 JSON。
7. 电脑文件同步的目标、进行中、完成、待处理和失败状态与实际结果一致；未再次点击同步前，本机新增、修改和删除不会自动应用到云端。
8. 设置、个人数据及目标与计划的分类均位于左侧子菜单，切换后显示对应内容与选中状态；对话仍使用原会话侧栏。设置页能找到个人与团队模型列表、MCP 工具以及云端电脑管理；个人数据的七个分类和目标、定时计划可访问，现有操作与权限没有因布局调整而消失。个人密钥不回显；电脑管理与任务控制显示服务端确认的真实状态。
9. 构造超过一屏的旁聊、任务、模型或电脑列表，能前后翻页并访问全部条目；搜索、筛选及数量变化后页码有效。长消息、长表单、任务详情和文档均可完整阅读或编辑，翻页不丢失输入；查看历史期间收到新消息不会强制切页。
10. PC 上修改并保存个人数据，服务端确认后云端即为新版本；同账号手机连接或重连后自动看到最新已确认内容，在线期间也能自动获得其他端已保存的更新。个人数据页面没有手动同步按钮或同步开关；保存失败、离线和跨端冲突时保留草稿并如实提示。
11. macOS 与 Windows 的窗口顶部均能找到页面后退、前进和当前左侧栏的收起／展开控制，不显示页面或会话标题标签；非对话页的按钮控制页面子菜单，不显示会话列表或右侧会话侧边栏。各窗口宽度下页面子菜单与会话侧栏位置和宽度对齐。放大电脑后仍能从顶部展开会话列表，且不改变控制权。窗口控制分别位于系统习惯的位置，与标签和操作不重叠。后退、前进切换页面或工作区后，草稿及电脑控制权保持正确；无对应历史时按钮不可用。
