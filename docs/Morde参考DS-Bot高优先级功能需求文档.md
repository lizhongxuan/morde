# Morde 参考 DS-Bot 高优先级功能需求文档

> 需求稿，描述目标和调整方向，不代表功能已完成。依据 [DS-Bot 功能对比及迁移评估报告](Morde与DS-Bot功能对比及迁移评估报告.md)、[PC 布局需求](<Morde PC端布局与云端电脑体验需求文档.md>)和项目根目录的 [AGENTS.md](../AGENTS.md)。

## 目标与范围

Morde 对标 Muse 的个人 Agent 体验：用户在长期主会话中与主 Agent 对话，主 Agent 根据需要使用工具和已授权的云端电脑，协调任务并委派子 Agent，最后在原会话中交付实际结果。PC 界面参考 DS-Bot 的对话布局、视觉和交互，接入 Morde 现有服务。

保留现有多会话和旁聊能力，各会话的记录和任务独立。子 Agent 属于实际任务的执行过程，不作为独立聊天对象。Bot 群聊、Bot 团队、多个独立 Bot、IM 和本地 Agent CLI 不在本需求范围内。

下面按优先级和序号排序：**P0 是第一里程碑必须完成的闭环；P1 是随后优先补强的体验和产物能力。** Morde 已有部分实现，本需求要求在现有能力上改进并验收，不预设全部从零开发。

云端 Agent 统一使用 DSH；模型、授权、审批、凭据、操作记录和产物继续遵守 Morde 现有边界。复用 DS-Bot 或上游 DSH 功能时，先检查兼容性和许可证，再通过现有机制接入。项目文件夹同步以根目录 AGENTS.md 中的**手动、单向**规则为准；旧文档中的双向或自动同步建议不适用于本需求。

## P0：第一里程碑

### 1. 以主会话为中心的 PC 界面

**怎么改：**

- PC 客户端和 PC 用户网页采用一致的对话布局。参考 DS-Bot 的消息样式、输入框、面板、间距和动效，保留 Morde 品牌。
- 左侧提供主会话、旁聊及必要导航；中间显示当前对话、消息发送状态和必要进展；右侧按需显示当前会话的任务、文件/产物和云端电脑。用户可以收起、切换或放大侧栏，输入框始终可用。
- 消息、任务、审批和电脑状态接入 Morde 的实际数据。切换页面或会话时保留对应草稿，不把其他会话的工作显示为当前会话的工作。任务详情默认突出用户需要的信息。
- 沿用现有 PC 布局需求中的窗口控制、分页、键盘操作和窄窗口规则；视觉改造不能移除现有云端电脑、同步、个人数据和设置入口。

**验收：** 在一个窗口中可发送主会话消息、打开任务详情和指定电脑；收起或展开侧栏后输入框仍可操作。新建并切换至少两个会话后，消息、任务和未发送草稿归属正确；窄窗口仍能完成相同操作。

### 2. 跨端持续对话与长会话

**怎么改：**

- PC 和 iOS 使用同一账号的持久会话、消息、任务进度和结果；客户端关闭、刷新或短暂断网，不取消服务端已受理的任务。
- 在现有 DSH 上下文压缩、历史读取和消息持久化基础上，补齐超过模型上下文窗口后的续聊与恢复。原始聊天记录仍可查看；无法取得必要历史时明确说明。
- 纯文字问答可直接回复，不要求用户先选择或启动云端电脑。重连和重试应确认原消息及任务状态，避免重复创建任务或重复执行已确认完成的操作。

**验收：** PC 和 iOS 均能发送消息并收到真实回复，同一账号在另一端打开同一会话可看到历史；任务运行期间关闭 PC，重连后看到真实进度及结果。构造超过模型单次上下文窗口的对话后，Agent 能利用此前关键要求，原文可查看；不同账号无法读取对方会话。

### 3. 执行中继续对话与任务关联

**怎么改：**

- 用户在主会话中继续发消息时，主 Agent 区分普通追问、任务修改、进度查询、停止指定任务和独立新任务；关联不明确时询问具体缺失信息。
- 优化现有消息路由和任务关联：同一执行范围内的重复请求或重试不重复启动工作；用户明确要求重新执行时可创建新任务。不同目标、附件或执行范围的请求不能因话题相同而错误合并。
- PC 和 iOS 显示消息的实际发送/受理状态及必要的任务关联；修改或停止正在执行的任务时，等待服务端确认后显示结果。不能因一条新消息擅自停止其他工作。

**验收：** 一个任务执行时，依次发送追问、修改和独立请求，系统关联正确；停止其中一个任务不影响另一个。对相同请求重试不产生重复执行；无法判断关联时，用户能看到明确问题并继续处理。

### 4. 主 Agent 委派子 Agent 与结果回传

**怎么改：**

- 在现有 DSH 子会话派发、后台结果回收和检查点基础上，完善主 Agent 的任务拆分、并行、依赖衔接和结果汇总。独立且资源不冲突的子任务可以并行；有依赖的工作等所需结果到达后再继续。
- 子 Agent 只能使用任务实际授权的工具和资源；同一电脑或文件等发生冲突时协调执行，不能互相覆盖。派发成功只表示工作已开始，子 Agent 失败、停止或结果未知时如实回传。
- 参考 DS-Bot 的派发、完整结果保存和中断恢复行为，检查并补齐 Morde 现有链路。主 Agent 收到结果后检查、汇总，再向原会话交付；断线或重启不得丢失已确认结果或重复执行已确认操作。
- 在任务详情中展示真实子任务及其状态，不生成虚构的角色、进度或结果。

**验收：** 一个复杂请求实际派出至少两个互不冲突的子 Agent 并行工作，主 Agent 汇总两者真实结果。一个子任务失败时，结果如实说明；关闭客户端或重启后仍能恢复查看，已完成操作不重复执行。

### 5. 任务进度、审批与用户接管提示

**怎么改：**

- 参考 DS-Bot 的状态卡片，在对话附近显示有实际变化的进展，并在当前会话的右侧任务区展示详细步骤、子任务、结果和产物。只显示当前会话实际关联的工作。
- 需要用户澄清或审批时，说明问题、操作对象和影响，提供回答、批准或拒绝入口；提交成功后继续原任务。暂停、继续和停止显示服务端确认的状态。
- 明确区分排队、执行中、等待用户、完成、失败、已停止和结果未知；数据暂不可用时提示状态待确认，不把缓存或断线当成完成。面板收起时仍能发现待处理事项。

**验收：** 同一会话中有两个任务时，各自进度、审批和结果对应正确。用户处理审批或澄清后原任务继续，刷新或跨端打开后状态一致；断网及结果未知时不显示虚假完成。

### 6. 指定云端电脑与常用工具

**怎么改：**

- 主 Agent 按用户要求使用已授权的指定云端电脑；PC 对话侧栏显示电脑名称、连接状态、实际控制权和画面，提供接管与交还入口。登录等需要用户参与时，提示用户在该电脑上处理后继续原任务。
- 复用 Morde 现有云端浏览器、桌面、终端、文件和搜索能力。任务只使用当前授权的电脑及文件范围；不能确定目标或权限、电脑不可用、工具失败时说明原因，不自动切换目标。
- 搜索任务返回可核查来源；终端和文件任务报告实际输出或失败。控制权、执行状态和最终结果以服务端确认的信息为准。

**验收：** 在指定且已授权的云端电脑上完成一次可观察的界面操作和一次终端命令；搜索一个问题并返回来源。用户可接管并交还电脑；电脑不可用或授权失效时，界面与回复显示真实状态，普通文字问答仍可进行。

### 7. PC 手动同步项目文件夹

**怎么改：**

- PC 端让用户选择本地文件夹和目标云端电脑，确认项目名与同步范围，再点击同步；项目名默认取本地文件夹名。显示目标、进行中、完成、待处理和失败状态。
- 每次点击将所选范围**单向**同步到指定电脑的 `~/workspace/project/<项目名>/`，保留相对目录结构。本机增改删只在用户再次点击后应用；云端变化不反向修改 PC。删除只作用于对应的已同步内容。
- 在现有同步链路上处理目标已有未协调内容、本机删除与云端独立修改等冲突：保留受影响内容并提示。同步根目录不可访问时暂停并提示，不能当作全部删除；校验项目名和目录范围，不能越出目标 `project` 目录。

**验收：** 首次点击后，文件和子目录出现在指定目录，Agent 能在授权范围内读取同步文件；本机新增、修改、删除后，在未再次点击前云端内容不变，再次点击后对应变化生效。云端变化不反向改动 PC；冲突、根目录不可访问或授权失效时保留受影响内容并显示真实状态。

## P1：优先补强

### 8. 会话搜索与历史定位

**怎么改：**

- PC 会话侧栏接入已有的会话标题搜索，用户可在当前账号有权访问的会话中查找并打开对应历史；分页和搜索结果保持一致。
- 主会话和旁聊保留原始消息浏览能力。Agent 按授权检索历史时，与用户界面的会话搜索使用各自现有权限边界；已删除或撤销访问的内容不再供新任务使用。消息正文全文搜索可在确有需要时另行完善。

**验收：** 输入标题关键词可找到并打开对应会话；多页结果不漏项或重复。其他账号、已删除或已撤权的会话不出现在搜索结果中。

### 9. 长期记忆的来源与变更管理

**怎么改：**

- 在已有个人记忆列表和开关上，增加记忆来源、变更时间与历史记录的查看入口，支持用户修改、删除及恢复可用的历史版本；已有记录没有来源时显示“未记录”，不补造来源。
- 服务端保存必要的变更记录，恢复时检查当前版本；跨端或并发修改发生冲突时保留现有内容并提示。用户关闭记忆后，个人对话不再读取受该开关控制的记忆和历史片段。
- 参考 DS-Bot 的管理体验，继续遵守 Morde 的用户授权和个人/项目隔离；自动整理只处理已授权的记忆，不保存凭据等敏感值。

**验收：** 用户可查看一条记忆的来源和变更、修改后恢复此前版本；来源未知时不会显示编造信息。跨端同时修改时不静默覆盖；关闭记忆后新任务不再使用受该开关控制的个人记忆。

### 10. Office 文件处理与交付

**怎么改：**

- 用户可在对话中要求主 Agent 创建、检查或修改授权范围内的 Word、Excel 和 PowerPoint 文件，处理结果作为任务产物在对话或文件面板中查看、下载。
- 在云端授权的工作环境中优先评估并接入兼容的 DSH Office 能力，再按需复用 DS-Bot 的 Office 处理代码。文件读取、修改、渲染和产物保存沿用 Morde 的授权、操作记录及产物校验机制。
- 处理成功后提供实际生成的文件及可用的检查或预览结果；格式、运行环境或渲染能力不可用时说明限制，不声称完成。跨端打开同一会话时可看到已确认的产物。

**验收：** 分别创建和修改一个 `.docx`、`.xlsx`、`.pptx` 样例，生成的文件可打开且包含要求的修改；PC 与 iOS 能看到同一已确认产物。处理失败或无权限时不显示为成功。
