Morde 统一风格方案

四个端（PC、Web 管理后台、工作台、iOS）现在各用各的颜色、圆角和字体。这一轮回到蓝色：之前被否的不是蓝色本身，是扁平的企业蓝（A–D）和太冷太安静的极简执行（E–H），可爱那轮（I–L）也不是蓝色。用户还是喜欢蓝色，所以这一轮是四种不同性格的蓝——全是浅色、活泼可爱，等待和加载状态都有动画。每个方案都用同一个对话界面渲染，内容、文案、动画状态完全一致，只换 token 和动画参数，方便直接比较哪套顺眼。

新版 M–P 参考了 Discord 亮紫 #5865f2 / Telegram 蓝 #229ed9 / 多邻国蓝 #1cb0f6 / Stripe 蓝 #533afd，2026-11-18。旧版：A–D 见 morde-unified-style-schemes-v1.html，深色 E–G 见 v2，浅色 E–H 见 v3，可爱 I–L 见 v4。

现状：四个端，三套品牌色

PC 端是 Electron 壳，加载的是服务器上的 web 页面，所以 PC 和 Web 管理后台共用 portal 的样式；工作台是独立应用、独立样式；iOS 是原生应用，直接用系统颜色，没有 Morde 自己的品牌 token。

新版思路（参考了谁）

被否的不是蓝色，是执行：A–D 是单色扁平企业蓝，大阴影，显旧；E–H 是克制极简、细线单色，太冷太安静；I–L 活泼可爱但不是蓝色。蓝色本身没问题——Discord、Telegram、多邻国、Stripe 都是蓝色起家，照样活泼。这一轮四种蓝，性格各不相同，N 还直接沿用现在的品牌青 #2e74a6，只换性格不换品牌色。

  • Discord：亮紫 #5865f2（blurple），圆角 + 贴纸 + emoji 文化；活泼但结构清楚；蓝紫渐变就是从这来的。
  • Telegram：蓝 #229ed9，干净、快、气泡圆润；蓝色也可以很轻很透。
  • 多邻国蓝 #1cb0f6：高饱和天蓝 + 3px 下边框按钮，元气满满；晴空蓝的参考。
  • Stripe 蓝 #533afd：蓝紫渐变 + 细腻排版；颜色少但层次多，极光蓝的参考。
  • 共同点：浅色底、圆角 18–24px、动效带弹性（springy cubic-bezier）、等待状态本身就是内容——吉祥物眨眼、圆点跳、进度条滑动。

为什么前三轮不合口味：A–D 扁平企业蓝显旧；E–H 克制极简太冷；I–L 活泼可爱但不是蓝色。这一轮：蓝色 + 活泼可爱 + 动画，N 还保留现在的品牌青 #2e74a6。

四个动画状态（纯 CSS 循环播放）

每套方案的 mockup 里都有同样的四个等待 / 加载状态，只换动画参数，方便比较动效风格。全部是 CSS @keyframes，无脚本，循环播放；幅度小、时长 1–1.6s，不晕。另外 M 的顶栏有一朵小云轻轻飘，N 的顶栏有三个小气泡往上冒——每套一个小点缀，其余四个状态完全相同。

  • 💭 思考中：小吉祥物眨眼 + 轻轻上下浮动，气泡里三个圆点轮流跳。
  • ⏳ 任务执行中：进度条是条纹填充，边滑边涨；卡片右上角有个小转圈。
  • 🔔 等待审批：审批卡上的“等待中”徽章像呼吸灯一样一明一暗。
  • ✨ 骨架屏：生成中的文字位置先放两条灰色骨架，一道微光从左扫到右。

选定后怎么落地

四套方案的落地路径相同，区别只在换多少：token 只有一份定义，各端各自映射，不再各维护一套色值。四套都是浅色蓝色，无深色。动效也写成 token：--d-dur（圆点跳动时长）、--d-ease（缓动曲线，弹跳用 cubic-bezier(.34,1.56,.64,1)）、--spin-dur、--p-dur、--sh-dur。

PC + Web 管理后台

改 web/portal 的 token 定义一处即可，PC 是加载 web 页面的壳，自动跟随。需要改的是 --brand / --brand-hover 及配套的 ink、muted、line、圆角变量；动画直接用同一套 CSS @keyframes。选 N 只改圆角和动效，品牌色不用动；选 O 要给主按钮和用户气泡加蓝紫渐变。

工作台

独立样式里把 --primary 换成选定方案的 brand、--radius 换成选定圆角，并去掉应用底色的青色径向光晕（或按方案 O 换成暖白底）。动效复用同一套 keyframes。其余结构不动。

iOS

新增一份品牌 token：brand、brand-soft、success、danger 等语义色写死为选定值，停止用 Color.accentColor 系统蓝当品牌色；系统语义色只保留给背景和文字层级。动效用 SwiftUI withAnimation(.spring) 或 UIViewPropertyAnimator 对应实现（圆点跳、呼吸灯、骨架微光都有现成做法）。

四套 mockup 内容、文案、结构、动画状态完全一致，仅 token 和动画参数不同。四套都是浅色蓝色，无深色。选定一套后，按上方路径逐端替换即可；未选的方案不产生任何代码改动。旧版：A–D 见 v1，深色 E–G 见 v2，浅色 E–H 见 v3，可爱 I–L 见 v4。
