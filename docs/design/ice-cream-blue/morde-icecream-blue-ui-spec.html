Morde 冰淇淋蓝 UI 设计规范

Morde 全端统一视觉语言的定稿说明：颜色、圆角、字体、间距、全部控件的样子与状态，以及等待 / 加载动画的参数。各端开发时以这份规范为准，不再各自维护一套色值。

方案 P · 冰淇淋蓝 定稿日期：2026-11-18 浅色 only · 无深色模式 品牌色 #60A5FA

1设计理念

冰淇淋蓝是 Morde 的统一风格：主色是柔和的淡蓝 #60A5FA，大面积底色是带一点蓝的奶油白 #F8FAFF，卡片和输入框用 24px 的大圆角，阴影是带蓝色的果冻软阴影。整体像一勺刚挖出来的冰淇淋——软、圆、凉凉的，但不甜腻。等待和加载状态不藏起来，而是做成轻轻动的小风景：思考时圆点慢慢跳、吉祥物眨眨眼，审批等待时徽章像呼吸一样一明一暗，让「等」这件事本身也显得安心。

它刻意不走另外两条路：不做扁平的企业蓝（太正经、显旧），也不做冷峻的极简黑白（太冷、太安静）。Morde 是一个人的个人智能体，每天陪着用户说话、干活、等审批——它应该像一个脾气好、靠得住的朋友，而不是一套办公软件。所以文字不用纯黑，用柔和的石板灰蓝 #334155；状态色也全部降了饱和，成功是薄荷绿、失败是珊瑚红，都不刺眼。

这套风格是用户在 2026-11-18 经过四轮方案对比后定下来的：从最初的企业蓝、参考 Linear / Vercel 的极简风、活泼可爱的撞色风，一路比到四个蓝色方案，最终选了最温柔的冰淇淋蓝（方案 P）。定稿之后，各端只换 token，不再争论风格。

柔软奶油感圆润慢动效亲切平静
不是企业蓝没有硬朗的直角、深蓝大色块和办公软件式的密排。
不是冷极简不用纯黑按钮、不用细线代替一切层次，保留柔和阴影和温度。
不是暗色全端浅色 only，不做深色模式，任何界面都不出现大面积深色。

4动画规范

冰淇淋蓝是四套蓝色方案里动得最慢、最软的一套：四个核心等待动画的时长 token 全部落在 1.5–1.8 秒（圆点 1.5 · 转圈 1.5 · 骨架微光 1.7 · 审批呼吸 1.8），缓动以 ease-in-out 为主，不用弹跳过冲；只有连续循环类（转圈、进度斜纹、微光扫过）用 linear 匀速，才不会一顿一顿。另有三个明确列出的例外，属于环境节奏、故意更慢，不算加载反馈：吉祥物浮动 2s（源方案 P 原值）、眨眼间隔 3.4s、进度条涨幅往返 3.2s。原则只有一句：动效是安抚，不是表演——慢、轻、幅度小，永远不抢内容的注意力，更不能让人晕。

5使用规则 Do / Don't

八组对照。新界面拿不准时，先对照这张表。

✓ Do · 这样做

  • 只用一种蓝：品牌蓝 #60A5FA 及其同色系深浅（#3B82F6 / #2563EB / #BFDBFE / #DBEAFE）。
  • 大面积永远留给奶油白 #F8FAFF 和白色，蓝色只出现在按钮、选中态、进度等小面积处。
  • 圆角保持大而一致：卡片 24、输入 16、按钮胶囊，不混用小圆角。
  • 阴影只用带蓝的果冻软阴影 rgba(96,165,250,.18)，轻、透、向上托。
  • 动效保持慢而软：核心加载动画 1.5–1.8s、ease-in-out 为主（例外只有动画规范里列明的环境节奏），等待状态必须带动画安抚用户。
  • 文字用石板灰蓝 #334155，次文字 #94A3B8，层级靠字重和大小拉开。
  • 状态色全部用柔和版：薄荷绿、琥珀、珊瑚红，不用高饱和原色。
  • 新控件先查这份规范的 token 表，缺 token 先补规范、再写界面。

✕ Don't · 不要这样

  • 不要任何深色界面和深色模式，全端浅色 only。
  • 不要把饱和蓝铺满大面积（整屏蓝底、蓝顶栏），蓝色是点缀不是底色。
  • 不要混入其他色相当主色：紫、绿、橙只能以状态色的小面积形式出现。
  • 不要尖角：禁止 0–6px 的硬朗小圆角出现在卡片和按钮上。
  • 不要快而弹的动效：禁止 0.2s 级的 snap、过冲弹跳和大幅位移。
  • 不要纯黑文字（#000）和纯灰边框，边框一律带蓝（#DBEAFE 系）。
  • 不要灰色硬阴影（rgba(0,0,0,.x) 大面积投影），阴影必须带蓝。
  • 不要在同一屏混用两套圆角 / 两套字体，圆体优先的字体栈全端一致。

6各端落地

token 只有一份定义，各端各自映射。落地顺序建议：先 PC / Web（改一处全端受益），再工作台，最后 iOS。

PC + Web 管理后台（portal）

PC 客户端是加载 portal 页面的壳，改 portal 的 :root 一处即可两端生效。变化最大的是品牌色：从现在的青色 #2E74A6 换成 #60A5FA，hover 从 #286A9C 换成 #3B82F6；背景从 #F7F9FA 换成奶油白 #F8FAFF；ink / muted / line 整组换成石板蓝灰系；按钮圆角从 10px 改胶囊，卡片圆角统一 24px，并给卡片和 Composer 加上果冻阴影。动画直接引入本规范的四组 @keyframes 与时长 token。

工作台（Workbench）

工作台是独立样式：把 --primary 从 #4263D6 换成 #60A5FA，--radius 从 6px 换成按控件分级的新变量（卡片 24 / 输入 16 / 按钮胶囊）；去掉应用底色的青色径向光晕，换成奶油白 #F8FAFF 平底；字体栈换成圆体优先。结构和布局不动，只换 token。

iOS（原生）
