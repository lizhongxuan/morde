# Morde PC 云端电脑统一工作台需求

## 目标与范围

在 Morde PC 对话页的云端电脑面板中，通过“桌面、终端、文件、VS Code”四个入口使用同一台当前选定且已授权的云端电脑。点击入口后连接或切换到对应功能，不为不同功能另建云端电脑。

本需求覆盖 PC 客户端内的云端电脑工作台和相应接入行为；保留现有桌面体验，不新增独立普通用户 Web 端。

## 功能与规则

- 四个入口始终指向当前选定的同一台云端电脑。切换入口不改变目标主机或控制权；主机不可用时显示原因，不自动切换到其他电脑。
- 点击入口后显示对应功能：桌面远程画面、可交互终端、主机文件管理器或 VS Code 网页编辑器。未选择的功能不应导致重复启动主机或终端。
- 终端在首次使用时建立会话；切换离开再返回时恢复或复用该会话。会话状态未知或中断时，提示用户核实后再创建新会话，避免重复执行命令。
- 终端、主机文件和 VS Code 应能访问同一台主机的工作目录；一个入口创建或修改的文件可从其他入口查看。文件管理支持浏览、打开和保存文件、上传下载，以及界面已提供的新建目录、重命名和删除操作。
- 各入口和操作继续遵守当前账号对该主机的授权及控制权要求。权限不足或控制权未就绪时，说明受限原因；需要控制权的写入和交互操作不得静默执行。
- 加载中、就绪、失败状态应明确显示。连接失败时提供适当的重试方式，不以空白页面表示成功。
- “Workspace”若继续保留在文件面板中，应与“主机文件”清楚区分；本需求不默认两者是同一存储位置。

## 验收条件

1. 在实际 Morde PC 客户端连接一台已授权的运行中云端电脑，四个入口均能打开对应功能；切换时仍是同一台电脑，桌面现有操作保持可用。
2. 在终端的工作目录创建一个测试文件，在主机文件面板和 VS Code 中均能找到并读取；从任一入口修改后，其他入口能看到更新内容。
3. 终端可执行命令；切换到其他入口再返回，已有终端会话可继续使用，重复点击不会无提示地创建第二个会话。
4. 文件面板中的浏览、编辑保存、上传下载及目录管理操作均能得到真实成功或失败结果；失败时显示原因，不误报完成。
5. 对未运行的主机、失效控制权或缺少功能权限的情况，界面显示对应状态且不连接其他主机、不执行未授权操作。

## 待确认

- “文件”入口是否只要求管理云端电脑的主机文件，还是也要求在 VS Code 中直接编辑 Morde Workspace。后者涉及 Workspace 与主机工作目录的存储关系，不包含在当前默认范围内。
