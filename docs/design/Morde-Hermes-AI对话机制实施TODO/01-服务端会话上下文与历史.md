## 任务

- [x] **H01-1（已完成）修复长前文阻断**：长历史、任务结果、来源、前驱、路由候选和聚合候选在路由上下文中改用有界头尾预览与截断标记；数据库原文不变。长消息精确去重校验完整 SHA-256、执行范围和授权快照；聚合选中后按 ID 重新读取并校验完整内容。
  - 验收：18 KB 以上前文后发短消息；相同前缀不同尾部、不同授权/附件范围的请求不误归并；真正重复仍幂等。
- [x] **H01-2（已完成）实现跨 Task 上下文预算与入口保护**：按已选模型容量计算路由输入预算，包含当前消息、历史、摘要、系统提示、输出和余量；估算沿用 DSH TokenMeter 的 4 个 UTF-16 字符/token 基准并对中日韩文字加保守余量。容量未知时按 4,096 token 下限处理并记录告警；超预算时先缩减候选、再放弃摘要或清空最旧历史正文，同时保留消息 ID、标记历史不完整，当前消息始终保留。模型网关和 DSH 协调器在预留计费及调用 Provider 前再次拦截超预算请求，并通过 DSH `max_tokens` 传递输出上限；Provider 明确返回上下文超限时映射为 `message_too_long`，保留不确定调用不重放规则。没有把 Task Session 压缩当作会话历史压缩。
  - 验收：短历史不无谓阻塞；超出模型窗口时保留当前消息和有效历史引用；容量未知、摘要失败和 Provider 超限有明确状态及有限恢复。
- [x] **H01-3（已完成）保证摘要覆盖和并发提交**：沿用摘要版本、消息序号、来源摘要和授权快照；新增超时、空摘要、仅有不完整提示、并发消息、过期版本和项目成员撤权用例。摘要未覆盖全部消息时保留不完整提示；无有效摘要且最近 8 条以外仍有消息时在路由上下文中标记不完整。提交冲突或摘要失败不会覆盖原文和现有有效摘要。
  - 验收：注入摘要超时/空结果、并发写入、版本冲突和权限撤销；旧摘要不能假称覆盖新消息。
- [x] **H01-4（已完成）按授权找回原文**：扩展 `morde_current_conversation_history_search`，支持关键词检索及按消息 ID 附近分页读取；结果包含 ID、时间、截断/部分结果标记。分页游标绑定 Task、Owner、Actor、Conversation、Project、来源摘要、消息锚点和授权快照；每页复核授权。项目历史过滤重新核对 Task、当前成员资格和历史边界，无法复核时 fail closed。跨会话个人记忆配置未变。
  - 验收：摘要之外的旧锚点可查回；当前协调器无法直接调用工具时，应路由到有权检索原文的 Task，或明确说明必要历史不可用；越权、伪造 Cursor、撤权和缺失历史不能泄露或编造。
- [x] **H01-5（已完成）记录验证与交接**：相关 Go 单测、Store 集成测试和隔离本地 PostgreSQL 用例通过；记录见下文。H03 需沿用的路由结构变化已列出。本任务未新增迁移。
