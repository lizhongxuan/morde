# Morde PC 端云端电脑侧边栏需求文档

## 目标与范围

调整 `morde-pc` 右侧边栏的云端电脑控制界面，参考提供的 Codex 截图，以居中的远程画面为主体，精简进入后的操作。视觉遵循 [Morde 统一 UI 规范](design/ice-cream-blue/morde-icecream-blue-ui-spec.html)。

本需求与[原 PC 布局需求](<Morde PC端布局与云端电脑体验需求文档.md>)中的云端电脑面板布局或按钮文案不一致时，以本文为准。

## 功能与规则

1. 打开云端电脑侧栏时，默认在面板中居中展示指定且已授权电脑的桌面画面。连接中或无法连接时，在画面区域显示真实状态。
2. 画面下方居中排列四个应用按钮，顺序为“桌面”“终端”“文件”“VS Code”；点击后在同一控制区域切换对应内容，并显示当前选中项。
3. 四个应用按钮下方只放一个控制权按钮：当前用户未接管时显示“接管控制权”；已有效接管时显示“归还控制权”。点击后执行相应操作，服务端确认后才切换按钮文案。
4. 沿用现有控制权限规则：未取得有效控制权时，四个应用按钮可见但禁用；有查看权限时仍可查看桌面画面。接管后，应用按钮按实际权限和能力开放，不可用时说明原因。权限不足或其他用户持有控制权时，接管按钮禁用并说明原因。
5. 控制权状态读取或切换中，显示真实进度并禁用操作按钮；失败时提示原因，结果未知时先核实状态，不能误报接管或归还成功。确认操作未成功且可以重试时，通过同一控制权按钮重试。
6. 移除控制区重复的主机状态操作栏和多余按钮，包括续期、重试交回 AI、适应窗口、键盘、Alt+Tab、找回窗口和全屏；连接或权限异常仍需提示。PC 顶栏的标签、放大及窗口操作，以及云端电脑管理入口保留。
7. 关闭或切换侧栏不自动改变控制权，也不停止云端任务。电脑不可用或未授权时说明原因，不切换到其他电脑。

## 验收条件

- 在真实 `morde-pc` 中打开云端电脑侧栏，默认看到居中的桌面画面；其下依次为四个指定应用按钮，再下方为一个控制权按钮，控制区没有上述多余按钮。
- 未接管时显示“接管控制权”，四个应用按钮禁用；在有查看权限时可观看桌面。服务端确认接管后显示“归还控制权”，可按权限切换四个应用；确认归还或控制权失效后恢复未接管状态。
- 检查连接中、断线、权限不足、接管或归还失败及结果未知的情况：界面显示真实状态，不能误报成功；状态未确认时不能重复提交操作。关闭或切换侧栏后，控制权和云端任务状态保持正确。
