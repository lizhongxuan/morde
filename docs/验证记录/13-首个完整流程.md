## 已知限制

文本和按键输入前会核对目标窗口为活动窗口，再用 XTEST 发送。外部焦点变化仍可能发生在检查与发送之间；xdotool 的 `--window` 使用 XSendEvent，部分浏览器会忽略，所以暂不使用。真实 Host GUI 验收需确认该窄竞态是否影响用户。
