## 二、三处纠正（我的复刻设计与你的 TODO 冲突的地方）

1. **合并窗口与 Planner 文件**：你的 02 明确写“本设计不预设独立 Planner 文件、固定 60 秒归并窗口，也不因缺少验收标准就一律追问”。我的复刻设计 P0-3 写了“新建 `conversation_planner.go`”、P0-4 写了“先定 60s 可配窗口”、P0-3 写了“无验收标准的 brief 不派发，直接 Clarify 问用户要验收标准”——三处都与你的 TODO 冲突。以你的 TODO 为准，修正为：Planner 是 Harness 内的一份职责（产出 brief 四件套），落不落独立文件由实现时定；合并窗口时长按实测调，不先定 60s；无验收标准时只在影响执行 / 安全 / 成本 / 不可逆结果时才问最少信息，不是一律追问。总计划文档里的 P0-3 / P0-4 表述与待拍板第 2 项按此修正。
2. **审批卡字段**：见 05 节。不是“只有三字段”，是“本体三字段 + 披露层一半”。
3. **验证者换模型家族**：见 06 节。不是 Muse 证据，是 Grok 进口，降级为建议。
