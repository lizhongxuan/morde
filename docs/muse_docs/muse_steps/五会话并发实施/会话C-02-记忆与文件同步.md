**设计与交接：**按[PC 单向文件夹同步](<01-复杂链路设计与交接.md#sync>)交付触发快照、源基线、Host applied 回执、冲突和部分应用状态；按[记忆与 Skill 设计](<01-复杂链路设计与交接.md#memory-skill>)先交来源/授权合同，再接入规则。

- [ ] **C02-1 授权记忆先交接。**复用既有记忆、索引、来源修订和授权检查；明确更正、撤权与遗忘的可用接口及状态，先把稳定合同交 B-02。
  - 验收：T30–T33 验证本账号授权历史、来源版本、纠正、确认遗忘和另一账号隔离；权限失效不能召回旧内容。实际 PC / 跨端由 E/A 分别记录。
- [ ] **C02-2 文件夹同步服务端。**沿用固定默认云电脑的 Workspace 同步、身份 / 路径授权、用户点击触发和 applied 回执；检查新增 / 修改 / 删除、非协作写入、源不可访问与未知回执。
  - 验收：T16–T18 的服务端测试确认不误删、不静默覆盖、不切换目标、不反向同步；回执 unknown 或多文件部分应用须对账且不推进 baseline，不能假定整批已回滚。需要共同变更的 schema / API 交 A，PC 文件选择和 IPC 交 E。

  - 验收：A02 验证未确认规则不生效、来源变化 / 撤权失效、账号隔离及高风险操作仍受审批；不把普通记忆自动升级为规则。
- [ ] **C02-4 支持真实云端与 Runtime 交接。**文件外发的全局限制已撤销；向 E 提供用户固定默认云电脑的同步合同及测试条件，使用任务授权范围内的合成目录；承接 B-02 所需的 Runtime 专属修改。
  - 验收：实际 PC → 真实目标及 Agent 读取由 E/A 按 T44 记录；本地 fixture 不能冒充云端通过。Runtime 插件仍遵守 DSH、权限与恢复合同。
