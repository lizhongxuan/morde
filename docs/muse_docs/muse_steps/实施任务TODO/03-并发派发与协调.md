## 任务

- [ ] **M03-01（未开始，依赖 M02-03）子树合同与持久化**：在 `agent_sessions.go`、`cloud_dsh_session_tree.go`、相关存储及调用方支持 root → child → grandchild；保存父/根身份、深度、调用 ID、目标及状态。验收：相同委派请求重复提交只产生一个子会话，跨用户/跨任务父子关联被拒绝。
- [ ] **M03-02（未开始，依赖 M03-01）DSH 两层委派**：评估上游插件；在 `engine.mjs` 委派校验及工具暴露处接通深度 2，禁止越级和扩大授权，继承预算、运行环境和根/父检查点栅栏。验收：两层可执行并返回实际结果；第三层受限并有明确错误，旧检查点不能继续派发。
- [ ] **M03-03（未开始，依赖 M03-02）协调、并发与汇总**：在子会话管理和任务计划中按依赖派发；独立工作并行，冲突资源加互斥或隔离；主 Agent 等待实际结果并区分失败、取消、未知与完成。验收：至少两个互不冲突 worker 的执行时间重叠，汇总包含真实结果；共享同一电脑的冲突动作不并发。
- [ ] **M03-04（未开始，依赖 M03-02）取消与恢复**：扩展列表、指定子树取消、重启恢复和回执对账；父任务取消或授权撤销按范围传播，不影响另一任务。验收：重启及重复派发不重复执行已完成动作，取消一个任务不终止另一个。

## 端到端验收

从实际 PC/iOS 提交复杂请求，观察 root、协调员及至少两个 worker 的身份、时间线和结果；插入一个失败并验证如实汇总，分别测试中途新消息、指定取消、断线与服务重启。限制和并发数量以真实资源及压测确定，不把其他项目的单机并发数当作 Muse 事实。
