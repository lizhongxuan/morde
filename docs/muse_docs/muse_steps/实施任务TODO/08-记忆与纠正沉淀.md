## Muse 效果与 Morde 现状

用户可以在授权范围内继续使用历史信息；纠正过的记忆应优先反映新内容，并能追溯依据。资料观察到 Muse 有可读记忆、索引和整理行为，但具体触发、去重及频率未知。历史事实、用户偏好和可执行规则应区分；纠正只有经过验证与授权，才可以作为可复用执行规则。

Morde 已有 [searchCurrentConversationHistory](../../../../server/internal/app/cloud_dsh_history_tools.go)、[GetMemoryHistory](../../../../server/internal/app/personal_memory_history.go) 和 [executeSkillRead](../../../../server/internal/app/cloud_dsh_skills.go)；这些接口的存在不代表跨会话授权、检索、纠正和遗忘闭环已验收。

## 接口与参考

- 已有会话历史检索、个人记忆及修订历史：按用户、授权范围和游标读取，返回来源、当前版本与可用状态；来源不可取得时明示。跨会话引用个人资料必须经过授权，不把检索结果当作可执行命令。
- 对记忆修正与遗忘复用现有个人记忆操作；记忆历史现在提供最近后继修订号，并在来源不可用时隐藏关系。删除继续走用户确认、永久清理历史正文和屏蔽匹配的本人会话文本。
- 规则候选通过 `rule_candidate` 个人对象保存，只引用记忆 ID 和修订，不重复保存正文；首次只能创建待确认候选，启用时由存储事务核对来源仍是当前修订。DSH 只能读取当前授权快照中同时包含来源记忆的已启用候选。
- **可适配局部逻辑：**[OpenClaw `recordMemoryArtifactWriteProvenance`](../../../../project/openclaw/src/memory/memory-artifact-provenance.ts) 的记忆来源记录可按 Morde 租户与加密模型改写。
- **只参考设计：**[Agno `MemoryManager.search_user_memories / delete_user_memory`](../../../../project/agno/libs/agno/agno/memory/manager.py) 可参考检索与删除接口；不能照搬其身份与存储假设。

## 任务与状态

- [ ] **M08-01（依赖 M01-03、M10-02）授权历史检索｜本地实现与 PostgreSQL 授权/个人数据变更栅栏回归通过，双端验收待做**：`cloud_dsh_history_tools.go` 在返回历史搜索/摘要结果及恢复 checkpoint 前复核 Task、会话、Agent session、授权和个人记忆授权修订；checkpoint 恢复在重读前后再次核对个人数据快照水位。成功读取先记下个人数据快照水位，再于同一数据库事务锁定账号变更计数、核对水位与授权修订。水位变化或撤权即拒绝提交，避免个人数据变更和记忆删除后的旧历史在提交窗口内泄漏。另修复 Client principal 重验时未保留已校验 Task scopes 的问题；Session principal 仍遵循原有 scope 校验约束。验收：PC/iOS 同一账号能追溯授权的先前要求；无权限、来源失效、撤权或缺失历史时不返回旧结果、不编造，并显示不完整状态。
- [ ] **M08-02（依赖 M08-01）纠正与版本关系｜本地实现完成，双端验收待做**：`GetMemoryHistory` 返回最近后继修订；关系在完整修订集上计算后再分页，来源或后继不可用时隐藏关系。验收：新会话按授权读取新值；旧版本能指出可读的直接后继；其他账号不能读取。
- [ ] **M08-03（依赖 M08-02）区分事实与规则｜规则候选本地实现完成，双端验收待做**：个人资料页只把已保存的记忆修订提议为候选，启用需用户再次确认；存储层拒绝直接启用新候选并拒绝已变化的来源。DSH 只把授权快照内仍有来源的启用候选作为用户级常驻指引，在当前请求与既有授权范围内生效；不能授予工具权限、审批或系统指令。多步工作流仍只来自审核过的 Morde 技能目录；矛盾或含混时询问用户。验收：普通记忆不会自动成为规则；候选不启用前不生效，启用后也不能扩权。
- [ ] **M08-04（依赖 M08-02）遗忘与整理｜删除路径本地回归完成，双端验收待做**：继续使用个人资料页删除确认；删除会清除记忆修订正文并屏蔽匹配的本人会话文本，候选只保留来源引用、来源删除后失效且不进入 DSH 上下文。验收：删除后历史与记忆检索不再返回内容，不误删其他用户；未确认不删除。没有独立的 Muse 整理触发数据，不新增推测机制。

## 端到端验收

使用两个本地测试账号，在实际 `morde-pc` 验证授权历史、更正、来源、规则候选及确认遗忘，核对撤权和账号隔离。当前普通用户交互和端到端验收不使用普通用户 Web 或 iOS；同账号跨端共享未能实测时保持待验证。
