## Muse 效果与 Morde 现状

用户可以在授权范围内继续使用历史信息；纠正过的记忆应优先反映新内容，并能追溯依据。资料观察到 Muse 有可读记忆、索引和整理行为，但具体触发、去重及频率未知。历史事实、用户偏好和可执行规则应区分；纠正只有经过验证与授权，才可以作为可复用执行规则。

Morde 已有 [searchCurrentConversationHistory](../../../../server/internal/app/cloud_dsh_history_tools.go)、[GetMemoryHistory](../../../../server/internal/app/personal_memory_history.go) 和 [executeSkillRead](../../../../server/internal/app/cloud_dsh_skills.go)；这些接口的存在不代表跨会话授权、检索、纠正和遗忘闭环已验收。

本轮补齐了个人数据页内“动态 / 灵感 / 偏好”的分类入口，避免全局侧栏精简后这三项失去可达路径；可安全重试的本地读取、同步和额度错误也保留页面级恢复按钮。Portal 组件定向回归 38/38 通过，但这只是源码组件证据，未在实际 `morde-pc` 运行验收，不关闭 M08-01–04。

## 接口与参考

- 已有会话历史检索、个人记忆及修订历史：按用户、授权范围和游标读取，返回来源、当前版本与可用状态；来源不可取得时明示。跨会话引用个人资料必须经过授权，不把检索结果当作可执行命令。
- 对记忆修正与遗忘复用现有个人记忆操作；记忆历史现在提供最近后继修订号，并在来源不可用时隐藏关系。删除继续走用户确认、永久清理历史正文和屏蔽匹配的本人会话文本。
- 规则候选通过 `rule_candidate` 个人对象保存，只引用记忆 ID 和修订，不重复保存正文；首次只能创建待确认候选，启用时由存储事务核对来源仍是当前修订。DSH 只能读取当前授权快照中同时包含来源记忆的已启用候选。
- **可适配局部逻辑：**[OpenClaw `recordMemoryArtifactWriteProvenance`](../../../../project/openclaw/src/memory/memory-artifact-provenance.ts) 的记忆来源记录可按 Morde 租户与加密模型改写。
- **只参考设计：**[Agno `MemoryManager.search_user_memories / delete_user_memory`](../../../../project/agno/libs/agno/agno/memory/manager.py) 可参考检索与删除接口；不能照搬其身份与存储假设。

## R12 / R15–R18 本地插件与合同审查（2026-11-24）

- 本机 DSH 源码仓库提交为 `fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159`，相关 skill、schedule、guard 包声明版本 `0.2.2-rc.1`、MIT；当前 Morde Runtime 的已固定依赖同为 `0.2.2-rc.1`，但仅版本号相同不证明本地源码和安装产物逐字相同，也未联网核对上游新版本。本轮未安装或升级依赖。
- **R15：**上游 `dsh-skill` 支持 provider 目录和 scope，`dsh-skill-filesystem` 可扫描项目、用户及自定义本机目录；当前 Runtime 未挂载这些包。Morde [cloud_dsh_skills.go](../../../../server/internal/app/cloud_dsh_skills.go) 使用经 Broker 和任务授权检查的固定嵌入式只读白名单。上游目录发现本身没有证明候选、用户明确批准、撤销、跨重启租户隔离及来源栅栏；直接挂载文件系统 provider 会越过当前目录与授权边界。受控候选生命周期和持久合同需由所属服务/存储范围设计，本会话不改数据库或扩大可写范围。
- **R16：**本机上游有 `dsh-schedule` / `dsh-tool-schedule`，提供 Host 范围的存储、定时和向 Session 投递；其 Host 范围列表/自身存储与 Morde 的账户、授权、任务和账本合同不能直接等同。Morde 已有服务端 goal/schedule Broker；候选规则与每次执行来源、撤权及审批应在既有服务合同内衔接，不能直接启用上游 Host 调度作为替代。相关持久合同不在本会话可写范围，保持阻塞。
- **R12/R17（2026-11-25 更新）：**`repeat-tool-reminder` 已按本地锁定版本接入 Runtime；以阈值 `[3,5,8]` 和 500 字参数预览发 advisory 提醒，提醒作为来源可追溯的 Agent 会话消息保存，重复授权调用仍按原 Broker 路径执行。它不持久化跨进程循环计数，也不能阻断工具调用。`timeout-policy` 仍未接入；即使接入也依赖工具声明时限和配合取消，不能强制停止不响应取消的执行。上游另有 `dsh-tool-executor-ptc` / `dsh-ptc-runtime` 的 DSH 程序式工具执行候选，当前未安装；它会替换对应 scope 的 native executor，其嵌套调用需要先证明全部经过 Morde Broker、审批、预算、账本与 unknown 对账，且资源和取消可控。不能据插件存在声称通用防循环、超时或 CodeAct 已完成。
- **R17/R18：**本地 `server/internal/evaluation` 有合成套件与盲评合同，但本轮没有可用真实模型/独立评测器或完成的 PC 全链路；不能把合成结果当真实质量评价。多账号规模、真实跨端和最终收口仍需隔离服务、数据库/客户端联调及其他会话的合同工作；不在本会话越界实施或声称通过。
