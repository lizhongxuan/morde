## Muse 效果与 Morde 现状

普通对话直接回复；有操作需求时按需使用工具；复杂任务拆成可独立完成或有依赖的工作。进行中仍接收用户追问、修改、停止或新的独立任务；关联不清先澄清。Muse 的分类算法及消息合并窗口未知，不预设固定秒数或关键词规则。

现有 [ConversationRouteWorker.RunOnce / safeConversationRouteDecision](../../../../server/internal/worker/conversation_route_worker.go)、[ClassifyConversationRoute](../../../../server/internal/worker/cloud_dsh_coordinator.go)、[ApplyConversationRoute](../../../../server/internal/store/postgres/conversation_route_actions.go) 和 [executeTaskPlan](../../../../server/internal/app/cloud_dsh_task_plan.go) 是接入点；不把存在函数等同于路由已准确。

## 接口与参考

- 已有路由分类及 `ApplyConversationRoute`：输入带消息身份、当前会话上下文及可关联任务；结果表达直接回复、查询、修改/追问、停止、新任务或澄清，并绑定目标任务和版本。应用决定时校验快照与身份；过期决定重新判断，不影响其他任务。
- 已有任务计划工具：需要时记录目标、范围、可验证的完成条件、约束、预算与交接信息；从用户要求可以合理推出的内容不强制追问，缺少执行所必需的信息才暂停澄清。
- **可适配局部逻辑：**[Magentic-UI `format_user_interjection`](../../../../project/magentic-ui/src/magentic_ui/teams/omniagent/_user_interjection.py) 可改写为将新消息交给对应任务的上下文格式；[build_handoff](../../../../project/magentic-ui/src/magentic_ui/teams/omniagent/_handoff.py) 可参考目标、上下文和交付物的交接组织。
- **只参考设计：**[LangGraph `StateGraph.compile`](../../../../project/langgraph/libs/langgraph/langgraph/graph/state.py) 可参考条件分支表达；不引入 LangGraph 作为第二套 Runtime。

## 任务

- [ ] **M02-01（未开始，依赖 M01-01）路由合同**：在现有 route worker、模型分类器和 `ApplyConversationRoute` 中统一意图、目标和快照字段；失败或关联不明走澄清/可解释错误。验收：普通问答、查进度、修改、停止和独立新任务分别落到正确处理路径。
- [ ] **M02-02（未开始，依赖 M02-01）执行中接续**：为新消息与活动任务建立明确关联，应用时检查任务版本及用户权限，过期结果不可覆盖新要求。验收：同时运行两个任务时修改或停止其中一个，另一个持续执行；指代含糊时不擅自停止。
- [ ] **M02-03（未开始，依赖 M02-01）任务说明与拆分**：在 `executeTaskPlan` 和调用方补充目标、范围、验收、依赖及预算等必要信息，交接给 03 的子 Agent；需要工具时沿用授权链。验收：复杂请求能形成可执行子任务；普通问答不启动云电脑或无谓拆分。
- [ ] **M02-04（未开始，依赖 M02-02）回归路由不确定性**：用同会话追问、连续多消息、不同任务名称和指代不清构造样本，记录路由与原因。验收：无固定合并窗口假设，模型失败不会静默操作错误任务。

## 已知缺陷

- 2026-11-23：问“上面那条信息说了什么”时分类四次全败——模型输出非法，四次调用各烧满 512 token 输出上限；兜底又把未解决的前序当成上下文缺失，让用户重发内容，失败传到下一条消息。修复：构造器仍发 512 token 最小窗口预算，DSH 协调器在已解析窗口容纳时按同一拟合校验抬到 2048；可存输出上限 4096 字节提到 16384 字节；非法输出留 1024 字预览进日志与落库行；兜底只在前序记录确实缺失时问“无法确认上下文”。

## 端到端验收

在实际 PC/iOS 各测试普通问答、后台任务中的追问与修改，以及第二个独立任务；任务状态和回复归属于正确会话。两个有资源依赖的动作按依赖执行，互不冲突的任务不互相阻塞。
