## Muse 效果与 Morde 现状

长会话超过模型窗口后仍能找回用户此前的重要要求，用户可查看原始聊天记录；不能取得所需历史时明确说明。Muse 的窗口、压缩触发及具体保留策略未证实，Morde 应根据实际模型窗口和测试确定。

现有 [fitConversationRouteContext](../../../../server/internal/worker/conversation_route_worker.go)、[compactConversationSummary](../../../../server/internal/worker/conversation_summary_maintenance.go)、[历史检索及分段读取](../../../../server/internal/app/cloud_dsh_history_tools.go) 与 [MordeCompactionEngine](../../../../runtime/morde-cloud-runtime/src/engine.mjs) 是基础；已有分段读和压缩代码不等于大消息及超长任务端到端已通过。

## 接口与参考

- 已有路由快照/摘要：保留摘要版本和可核对来源；输出上下文预算及历史不完整状态，根据模型能力留出响应与工具空间。跨任务摘要与单次 DSH 执行会话压缩分开，不删除原始会话记录。
- 已有 `executeCurrentConversationMessageRead`：按授权的消息身份、内容哈希和字符偏移分段读取，调用方处理游标、边界及来源；补足大消息从收件、分类、任务派发、分段读取到结果的全链路。原文有变化、丢页、校验不符或无权限必须报错，不把截断预览当全文。
- **优先复用 DSH 插件：**[BasicCompactionEngine.compactIfNeeded / compactRegion](../../../../project/deepseek-harness/packages/compaction/compaction-basic/src/index.ts) 与现有 `MordeCompactionEngine` / `ToolResultPruner`；按当前版本核对触发、调用结果成组边界、检查点与恢复。
- **可适配局部逻辑：**[Hermes `_plan_compaction_window / summary_view`](../../../../project/hermes-agent/agent/context_compressor_window.py) 可参考选择压缩窗口与恢复原始来源；[ContextCompressor.should_compress / compress](../../../../project/hermes-agent/agent/context_compressor.py) 可参考预算判断和失败处理，不照抄阈值或覆盖原始记录。

## 任务

- [ ] **M10-01（未开始，依赖 M01-01）路由上下文与摘要**：检查 `fitConversationRouteContext`、摘要维护及分类输入，按实际模型 token 窗口裁剪并保留用户目标、来源与不完整标记；摘要失败不能编造内容。验收：超过模型单次窗口的对话仍可正确处理当前消息，缺失必要历史时诚实提示。
- [ ] **M10-02（未开始，依赖 M10-01）按需读取原文**：用 `searchCurrentConversationHistory` 按授权检索历史及来源；用 `executeCurrentConversationMessageRead` 按消息身份、哈希和字符偏移分段读取当前任务的原始用户消息，确保多字节字符边界正确。验收：早期、中间、最近的关键要求均能定位来源；跨账号及被撤权记录不可读，缺页或哈希变化明确报错。
- [ ] **M10-03（未开始，依赖 M10-02、M02-01）1 MiB 单条消息链路**：核对收件、路由、任务简报及分段读取的各处限制；利用现有有界读取，补齐按顺序分段处理、逐页 SHA-256 校验和汇总，不把全部内容塞进单次模型上下文。验收：1 MiB 纯文本在不同页埋入三个锚点，结果包含三个正确锚点及对应页/来源，每页 SHA-256 校验可追溯；损坏或缺页报错，超时说明已读页数与剩余量，不静默跳过。PC/iOS 和 API 的输入限制需同步核验。
- [ ] **M10-04（未开始，依赖 M03-01）DSH 执行会话压缩**：在 `engine.mjs` 检查已接入压缩与工具结果剪枝的实际调用；保留工具调用/结果配对、授权来源和原始记录，压缩无进展或失败时显示真实错误。验收：多轮工具输出超过窗口前可压缩并继续，重启与取消后检查点可恢复，不引用被删改内容。
- [ ] **M10-05（未开始，依赖 M10-01、M10-04）预算与保护回归**：分别用小窗口、大窗口及包含中文的消息验证 token 估算和页边界，记录实际阈值。验收：预算不足时可恢复或明确失败，不静默截断关键要求；原始聊天仍可查看。

## 端到端验收

在实际 PC/iOS 使用同一账号进行超过所选模型窗口的多轮对话，询问早期要求并核对原始来源；再按 M10-03 用本地合成 1 MiB 消息验证分段完整性。无权限或原文不可用时不得编造；使用本地测试环境，不外发文件。
