# Morde 主会话云端 Agent 文件空间需求文档

> 需求文档，描述期望行为，不代表功能已实现。

## 目标与范围

主会话的“文件”面板用于查看当前用户自己的云端 Agent 文件空间。该空间就是云端电脑的 `~/workspace/` 目录，按用户归属，不按会话或任务分开。本需求只定义云端文件空间的查看，不包含本机文件管理或同步规则。

## 功能与规则

- 文件面板从当前用户的云端 Agent 文件空间浏览目录和文件；云端 Agent 与云端电脑访问同一份 `~/workspace/` 内容。
- `~/workspace/` 根目录不依赖云端电脑构建成功，必须在用户获得云端 Agent 文件空间时存在。云端电脑尚未构建或构建失败时，根目录仍可查看；电脑就绪后继续使用该目录，不另建一份替代目录。
- 文件空间按用户隔离。若空间暂时不可读取，界面显示读取失败，不得将错误显示为空目录。

## 验收条件

- 用户打开主会话文件面板，看到自己的 `~/workspace/` 根目录及其中实际存在的内容。
- 在云端电脑尚未构建或构建失败时，用户的 `~/workspace/` 仍存在并可见；电脑构建成功后，Agent 与电脑看到的是同一目录及文件。
- 文件空间读取失败时显示失败状态；空目录时显示空目录。其他用户无法查看该用户的目录或文件。
