# Morde Harness 各会话开发提示词

本文件提供 S00 协调会话和 S01–S09 专项会话的可复制提示词。S00 先完成共同基线；每个专项会话从同一基线的独立 worktree 启动。S01–S09 是有依赖的工作流，不要求同时改代码；按各提示词中的依赖解锁任务。

## 所有会话共同遵守

- 先读根目录和目标目录适用的 `AGENTS.md`、`docs/Morde_Harness_最终流程与实现规格.md`、`docs/Morde_Harness_实施任务_TODO.md`、`docs/Morde_Harness_并发实施/00-并发实施总控.md` 和本会话任务文档。以最终规格为行为依据，以主 TODO 为 H 编号、状态和验收的唯一事实来源。
- 检查并保留工作区已有改动；只在 S00 确认的共同基线和各自 worktree 中工作。仅修改本会话文档列出的 H 子项和文件边界。遇到跨 owner 的接口或数据变更，先提交最小提案，由对应 owner 实施。不得互相覆盖或自动 stash 其他工作。
- 失败先保留最小复现并追查完整调用链和机制根因。复杂问题先形成方案，记录根因证据、备选方案与取舍、选定机制、模块/函数职责与接口、状态/副作用归属、验收和风险；实现后将方案留在对应 H 项或获协调会话确认的设计文档，不能只留在聊天里。保持高内聚、低耦合和清晰的函数边界；不得靠扩大测试阈值、截短输入或放宽断言掩盖问题。长上下文要区分字符/字节/token、API 限制与模型窗口，检查检索、预算和压缩机制；用明确单位的合成历史做规模测试，并按目标模型窗口验证。
- 遇到 Hermes 同类功能，先核对固定上游 SHA `0d49d6d9d20e461155d49ba9d188687079c811af` 对应源码、调用链、许可及测试。兼容时优先移植最小实现和配对测试；本地快照未核对哈希时不能声称源码级移植。维持 Morde/DSH 的用户/会话隔离、授权、预算、审批、幂等和对账边界，不复制第二套 Agent Loop 或不兼容信任模型。
- 需要子 Agent 时，先自行拆分，再为每个子任务明确 H 范围、文件清单、接口和验收。只委派互不依赖且文件不重叠的工作；子 Agent 不得编辑别的 owner 文件、共享 TODO 或总控。主会话负责复核、集成和最终报告；无法划清文件边界时不要并行委派。
- AI/Provider 测试通过 Morde 模型网关和本机已配置的密钥运行。密钥只从本地环境变量或密钥存储读取，例如 `DEEPSEEK_API_KEY`；禁止写入提示词文档、源文件、命令参数、日志、截图或验证记录，也不得绕过 Morde 网关直连 Provider。已在聊天中明文出现的 API key 应按已暴露处理，使用前先撤销并轮换；新密钥缺失时记录为未验证。
- 只有 S07 可访问本文件指定的共享远程测试实例；S01–S06、S08、S09 使用本机隔离环境和合成数据，避免并发污染共享环境。所有会话遵守根 `AGENTS.md`：项目文件只在本地读写，不上传/外发。测试结果须区分单测、模拟、真实 Provider、真实客户端和远程集成，不得把未覆盖项写成通过。
- 每个专项会话结束后向 S00 提交改动、根因与方案记录、文件列表、Hermes 对照、实际验证命令/结果和未测风险。专项会话不直接修改主 TODO 的状态；S07 只写验证记录 H06 证据段，S00 在复核证据和整合后统一更新主 TODO 状态及共享章节。

## S07 测试环境变量

只在 S07 使用这些变量；值由用户在本机密钥存储或本地进程环境中配置，不写进本文件。禁止用 `env`、`set -x` 等方式打印全部环境变量。

| 变量 | 用途 |
|---|---|
| `MORDE_TEST_BASE_URL` | 指定站点 `https://portal.120.25.178.93.sslip.io` |
| `MORDE_TEST_SSH_HOST` | 指定主机 `120.25.178.93` |
| `MORDE_TEST_SSH_USER` / `MORDE_TEST_SSH_PASSWORD` | 仅在获准且确有需要时检查测试机 |
| `MORDE_TEST_ADMIN_USER` / `MORDE_TEST_ADMIN_PASSWORD` | 登录指定测试站点 |
| `MORDE_TEST_DATABASE_URL` | 仅在管理员登录失败且需按用户授权重置密码时使用；先验证目标库身份 |
| `DEEPSEEK_API_KEY` | Morde 模型网关测试配置所需的本地 Provider 凭据 |

聊天中曾明文出现的 DeepSeek key 应视为已暴露，先撤销并轮换，再配置新值。缺少所需变量时记录阻塞，不从文档、shell history 或日志搜寻/复述秘密。
